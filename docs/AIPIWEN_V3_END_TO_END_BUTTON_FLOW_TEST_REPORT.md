## 5. 未在 Production 执行的按钮

以下操作会写数据、改变账号状态或打开本机文件选择器，因此没有在 Production 直接点击：

- 客户扫码上传：会创建 attribution token；
- 代客户上传：当前 Production 旧版会创建 token 并跳公开页；
- 文件选择/拍照上传：需要隔离 fixture；
- 报告生成和 report-store：会创建报告/客户记录；
- AI 方案生成/保存：会写真实客户 interpretation；
- 退出登录：会销毁当前 Session；
- OTP 获取和登录提交；
- 管理员审批、驳回、assign；
- 邀请链接复制和二维码下载。

这些分支已由隔离 DOM、BFF、RPC、CSRF、RLS 和合约测试覆盖，但不等同于新版本 Preview 浏览器 E2E。
