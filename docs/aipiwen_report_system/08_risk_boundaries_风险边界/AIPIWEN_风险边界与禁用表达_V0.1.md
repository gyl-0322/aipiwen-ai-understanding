# AIPIWEN 风险边界与禁用表达 V0.1

## 总边界

AIPIWEN 提供的是行为与关系理解参考，不替代医学、心理诊断、临床评估、教育专业评估或法律建议。

## 禁止表达

- 精准诊断
- 测出问题孩子
- 心理疾病判断
- 攻击性检测
- 天赋决定命运
- 保证改善
- 一定适合 / 一定不适合
- 你就是这种人

## 关系报告边界

- 不评判任何一方。
- 不把冲突归咎于某个人。
- 不劝分、不劝合。
- 不输出操控对方的建议。

## 团队报告边界

- 不用于招聘淘汰。
- 不做成员优劣排序。
- 不做风险人员筛查。

## 升级提醒

当用户出现自伤、伤人、严重失眠、持续惊恐、严重家庭暴力等情况时，应建议寻求线下专业支持。
