# AIPIWEN 资料命名与归档规则 V0.1

## 命名格式

建议格式：

`来源_主题_日期_资料类型_状态.md`

示例：

- `小鹅通_肖老师亲子解读_2026-06_课程链接_待核验.md`
- `模板_亲密关系合看_结构提取_待处理.md`

## 状态标记

- `原始`
- `转写`
- `Claude整理`
- `摘要`
- `待核验`
- `已脱敏`
- `可提炼`
- `归档`

## 归档规则

- 原始资料进入 `01_raw_materials_原始资料`。
- 方法论进入 `02_methodology_方法论提炼`。
- 报告结构进入 `03_report_templates_报告母模板`。
- 脱敏案例进入 `04_case_library_案例库`。
- 表达方式进入 `05_language_library_话术库`。
- AI 规则进入 `06_prompt_rules_AI规则`。
- 风险边界进入 `08_risk_boundaries_风险边界`。

## 禁止

- 禁止存放真实密钥。
- 禁止存放未脱敏用户隐私。
- 禁止将商业机构名称原样暴露为前台输出口径。
- 禁止将未经核验的课程摘要直接接入产品。
