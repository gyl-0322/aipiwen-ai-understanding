# AIPIWEN 报告系统升级总控备忘录 V0.1

## 当前目标

建立 AIPIWEN 报告系统的本地知识库底座，先完成资料归档、模板登记、方法论提炼入口和风险边界。

## 当前不做

- 不接入正式报告生成。
- 不接入前端运行时。
- 不调用 AI API。
- 不改变现有报告接口。
- 不把老师课程或外部资料直接作为上线内容。

## 报告系统方向

1. 个人完整报告
2. 亲子关系合看报告
3. 亲密关系合看报告
4. 团队协作理解报告

## 核心原则

- 不诊断。
- 不贴标签。
- 不玄学化。
- 报告是理解参考。
- 先理解真实行为，再结合已有资料。
- 统一使用沐海星辰语言体系。

## 后续任务

- 关系报告模板吸收升级
- 个人完整报告模板升级
- AI 解读 Prompt 规则升级
- Obsidian 知识库调用方案
