## 2. 标准解读流程

1. 开场说明：报告是理解工具，不是判断、诊断或定命。
2. 先确认用户问题：用户最想解决什么，而不是按指标从头念。
3. 识别对象和场景：成人、孩子、亲子、伴侣、团队不同入口不同。
4. 按核心指标解释：TRC、ATD、行为模式、学习通道、左右脑、五大功能区。
5. 做组合判断：避免单点指标决定结论。
6. 回到真实场景：学习、沟通、职业、亲子、关系或协作。
7. 给行动建议：以一周内可做的小动作优先。
8. 收尾边界：说明报告是参考，复杂状态建议专业支持。

## 3. 开场“中正”说明

前台可用表达：

- 这份报告不是为了判断谁好谁坏，而是帮助你更中正地理解自己或对方。
- 报告里的指标代表倾向和节奏，不代表命运或绝对结果。
- 我们会先看你现在最想解决的问题，再选择对应的解读方式。

禁用表达：

- 这个指标说明你就是这样的人。
- 这个孩子有问题。
- 你们关系注定会这样。

## 4. 定量与变量

定量部分是报告中较稳定的指标，例如 TRC、ATD、学习通道、行为模式和五大功能区。变量部分包括年龄、环境、教育方式、家庭互动、职业阶段、关系压力和当前事件。

解读规则：

- 定量提供底层倾向。
- 变量解释为什么同一指标在不同阶段表现不同。
- 报告输出必须同时看定量和变量，不能只看数值。

## 5. 带着用户问题解读

用户上传报告或描述行为后，先识别问题类型：

| 用户问题 | 优先调用 |
| --- | --- |
| 我看不懂这份报告 | 快速读懂版 |
| 孩子为什么这样 | 孩子行为理解报告 + 案例库 |
| 我适合做什么 | 个人完整报告 + 职业/学习建议 |
| 我和孩子怎么沟通 | 亲子关系合看报告 |
| 我和伴侣为什么总误会 | 亲密关系合看报告 |
| 团队怎么分工 | 团队协作理解报告 |

## 6. 不否定用户当前状态

职业、学习和关系建议不能直接否定用户现状。尤其是成人职业案例中，要先承认已有路径的价值，再给过渡建议。

可用表达：

- 你现在的路径并不是错的，只是可能还有更省力的使用方式。
- 可以先在现有工作中增加更匹配你的角色比例，而不是立刻推翻重来。

禁用表达：

- 你现在做错行业了。
- 你不适合这个职业。
- 必须马上换方向。

## 7. 职业案例中的过渡建议

以“房地产中介 + 医学背景”类成人职业案例为模板，Report OS 只保留结构，不保留隐私细节：

1. 看现有职业里已经沉淀的资源。
2. 看原有专业背景能否变成信任资产。
3. 看指标偏好适合销售、顾问、陪伴、专业解释还是资源整合。
4. 给过渡建议，而不是否定现状。

可用等级：B，需安全改写后输出。

## 8. 亲子个案中的行为理解

亲子解读优先解释行为背后的需要，而不是评价孩子。

结构：

1. 你看到的行为。
2. 这个行为不一定代表什么。
3. 可能涉及的底层特质。
4. 孩子的真实需要可能是什么。
5. 家长可以怎么回应。

前台边界：不判断孩子，不诊断家庭，不评价老师。

## 9. 典型类型讲法

| 类型 | 安全讲法 | 禁用讲法 |
| --- | --- | --- |
| 超级认知 | 需要能讨论意义和方向的导师型陪伴 | 天生高级、注定成功 |
| 逆思型 | 先看到风险和边界，不等于故意对抗 | 叛逆、唱反调、有问题 |
| 模仿型 | 通过示范和重复更容易掌握 | 没主见、只会照抄 |
| 开放型 | 先体验再筛选，更容易保持动力 | 三分钟热度、不稳定 |

## 10. 五大功能区生活化讲法

| 功能区 | 生活化表达 |
| --- | --- |
| 精神功能 | 目标、愿景、意义感和启动方向 |
| 思维功能 | 理解、分析、判断和拆解问题 |
| 体觉功能 | 身体感受、动作体验和真实陪伴 |
| 听觉功能 | 倾听、语言、问答和复述确认 |
| 视觉功能 | 图像、结构、观察和可视化判断 |

## 11. AI 三层解读产品逻辑

| 层级 | 适合内容 | 边界 |
| --- | --- | --- |
| 免费解读 | 快速读懂、低风险指标说明、轻量建议 | 不做深度关系判断 |
| AI 问答 | 围绕用户问题调用指标卡、案例卡和话术卡 | 必须标注置信度和边界 |
| 人工专家解读 | 复杂亲子、亲密关系、职业转折、多指标冲突 | 不自动前台输出 |

## 12. 适合前台的内容

- 中正开场说明。
- 安全改写后的指标解释。
- 行为理解结构。
- 低风险案例和一周行动建议。
- 关系沟通翻译句。

## 13. 只适合人工专家的内容

- 复杂亲密关系冲突。
- 涉及严重情绪、睡眠、家庭暴力、自伤伤人风险的内容。
- 未经校验的外部培训原话。
- 老师现场强语气判断。
- 需要跨多指标深度组合的职业转向建议。

## 14. 必须禁用的表达

- 医学或心理诊断：抑郁体质、心理疾病、ADHD、障碍、有问题。
- 绝对化：一定会、绝对、必然、注定、永远。
- 伤害性标签：懒、白眼狼、不懂感情、脚底板人。
- 玄学化：前世、天命、缘分密码、命中注定。
- 关系断言：婚姻一定有问题、你们不适合。

## 15. V0.2 真实录音增补：问题导向解读流程

真实转写稿显示，老师不是按报告逐项死念，而是先看用户问题，再决定解读路径。新手可以先按固定流程走，熟练后必须回到用户真实问题和场景。

标准顺序：

1. 开场中正：先说明数据没有绝对好坏，报告用于理解，不用于贴标签。
2. TRC：看信息节奏、注意力使用方式和任务切换。
3. ATD / APD：看反应节奏、压力感受、情绪和家庭互动氛围。
4. 行为模式：看启动方式、动力来源和任务推进方式。
5. 学习通道：看听觉、视觉、体觉等信息进入方式。
6. 左右脑底色：看整体偏好和处理信息路径。
7. 五大功能区：看精神、思维、体觉、听觉、视觉的生活化呈现。
8. 综合解读：看指标组合，不做单点判断。
9. 职业 / 亲子 / 关系建议：根据用户问题切换输出重点。
10. 总结行动：给当前场景可执行的一两个动作。

调用规则：

- 用户问职业，围绕现有工作、专业背景、资源和未来方向解读。
- 用户问孩子行为，围绕行为背后的节奏、需要和回应方式解读。
- 用户问亲密关系，围绕双方差异、冲突触发点和沟通翻译解读。
- 用户只想快速读懂报告，先给简版结构，不展开复杂推断。

## 16. V0.2 真实录音增补：中正开场话术

前台可用安全话术：

- 这份报告不是为了判断谁高谁低，而是帮助你理解自己、孩子或关系里的使用方式。
- 数据没有绝对好坏，每个特质都像手指长短，各有作用，关键是放在什么场景里使用。
- 同一个指标在不同年龄、关系和环境中会呈现不同状态，所以我们会先看你现在最想解决的问题。
- 如果你看到某个数值高或低，先不要急着给自己或孩子贴标签，它更适合作为理解线索。

内部提醒：

- 老师现场会用较强语气帮助学员记忆，但前台必须改成“倾向、可能、场景、建议”。
- 不使用“最厉害、最差、一定、绝对、天命”等强判断词做产品输出。

## 17. V0.2 真实录音增补：定量与变量

报告数据属于定量，年龄、关系、场景、环境、角色和用户当前问题属于变量。Report OS 输出时必须把定量放进变量里解释。

年龄阶段规则：

| 年龄阶段 | 解读重点 |
| --- | --- |
| 3-7 岁 | 生活习惯、感官需要、亲子回应和基础环境支持 |
| 7-13 岁 | 学习通道、兴趣班、写作业方式、规则和情绪接纳 |
| 14-18 岁 | 自我认同、学业压力、亲子边界和方向感 |
| 19-25 岁 | 专业选择、关系探索、独立性和自我使用方式 |
| 26-35 岁 | 职业路径、亲密关系、资源积累和角色切换 |
| 36-45 岁 | 事业稳定度、家庭责任、优势再调用和关系经营 |
| 46 岁以后 | 经验整合、长期价值、家庭/事业角色再平衡 |

同一数据在不同关系中的输出不同：

- 亲子场景看陪伴方式和误解点。
- 亲密关系看节奏差异和沟通翻译。
- 事业场景看优势调用和风险缓冲。
- 朋友或团队场景看协作边界和角色互补。

## 18. V0.2 真实录音增补：职业建议规则

成人职业解读必须遵守：

1. 不否定用户当前工作。
2. 先找现有行业里的优势调用点。
3. 再给长期适配方向。
4. 可以给“主业稳定 + 副线探索”的 80% / 20% 精力比例建议。
5. 现有行业可以继续做，但要找到天赋发挥点。
6. 过往失败经历只能作为风险线索，不作为否定标签。
7. 职业建议要同时结合专业背景、过往资源、现有行业和未来可能性。

前台可用表达：

- 你现在的工作不需要被直接否定，先看它里面哪些部分能调用你的优势。
- 可以把大部分精力放在当前稳定收入上，同时用小比例精力验证更匹配的方向。
- 过去没有做成的经历，可以作为风险提醒，帮助你设计更稳的过渡方式。

## 19. V0.2 真实录音增补：AI 三层解读

| 层级 | 作用 | 可输出内容 | 边界 |
| --- | --- | --- | --- |
| 免费基础解释 | 解决用户对报告约 30% 的基础理解 | 指标含义、区间说明、低风险解释 | 不回答复杂亲子、职业和关系判断 |
| AI 问答式解读 | 上传报告后围绕问题问答 | 教养、职业、兴趣班、陪伴方式、关系沟通 | 必须提示 AI 是辅助，不等于专家判断 |
| 人工专家深度解读 | 处理高复杂度问题 | 复杂亲子、亲密关系冲突、职业转型、团队冲突 | 不自动前台输出，需人工判断 |

复杂问题升级人工专家的触发条件：

- 用户长期困扰、情绪或睡眠明显受影响。
- 亲子冲突已经持续升级。
- 亲密关系出现严重冲突或安全风险。
- 职业转型牵涉重大财务或家庭风险。
- 团队冲突牵涉岗位、权责和组织风险。
