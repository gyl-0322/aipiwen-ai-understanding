# AIPIWEN 解读方法论提炼总表 V0.1

## 方法论主线

AIPIWEN 的报告解读以「行为倒推」为入口：先看用户眼前真实困扰，再结合左右脑底色、ATD 深解、TRC、学习通道、行为模式和功能区组合，帮助用户理解行为背后的需求、节奏和沟通方式。

## 核心模块

| 模块 | 当前作用 | 后续用途 |
| --- | --- | --- |
| 行为倒推 | 从真实行为进入理解 | 行为理解报告、亲子报告 |
| 左右脑底色 | 解释反应方式和处理信息偏好 | 个人完整报告 |
| ATD 深解 | 理解敏感度、反应速度和压力感受 | 个人/关系/团队报告 |
| 君臣佐使组合判断 | 避免单点解读，用组合看整体 | 高阶报告结构 |
| 案例库 | 提供具体场景和语言温度 | 报告表达升级 |
| 话术库 | 统一沐海星辰表达方式 | 前台文案和 AI 输出 |
| AI 规则库 | 约束输出边界和结构 | Prompt 升级 |

## 禁止偏差

- 不把单一指标解释成命运。
- 不把类型解释成人格标签。
- 不把关系问题归咎于任何一方。
- 不输出医学或心理诊断。
