## 7. 是否命中知识索引

接口响应未直接暴露知识索引命中详情，因此无法从线上返回中直接确认具体命中的知识卡编号。

从代码路径观察：

- `/api/generate-report` 会调用 `searchReportKnowledge(...)`
- 会构造 `reportKnowledgeBlock`
- 会构造 `riskKnowledgeBlock`
- 检索失败时会回退到内置 `SYSTEM_PROMPT + 硬编码规则 + engineResult + selectedIssues`

本次只能记录为：知识索引接入链路存在，但线上响应未暴露命中明细，不能直接确认命中哪条知识索引。
