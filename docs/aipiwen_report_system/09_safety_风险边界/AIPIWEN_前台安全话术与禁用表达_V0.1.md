# AIPIWEN 前台安全话术与禁用表达 V0.1

## 1. 总原则

AIPIWEN 前台输出只做行为、关系、学习和协作理解参考，不做医学诊断、心理诊断、命运判断、关系裁决或人员筛查。

老师录音中的现场表达可以作为内部专家参考，但进入产品前台必须安全改写。

## 2. 禁止医学 / 心理诊断

禁用：

- 抑郁体质
- 心理疾病
- ADHD
- 障碍
- 有问题

安全改写：

- 如果这个状态长期影响睡眠、学习、情绪或生活，建议寻求专业评估。
- 这个表现可能和压力、节奏或环境变化有关，需要结合真实情况观察。
- 报告不能替代医学或心理专业判断。

## 3. 禁止绝对化

禁用：

- 一定会
- 绝对
- 必然
- 注定
- 永远

安全改写：

- 更容易
- 可能
- 在某些场景下
- 倾向于
- 需要结合环境和阶段来看

## 4. 禁止伤害性标签

禁用：

- 懒
- 白眼狼
- 不懂感情
- 脚底板人
- 婚姻一定有问题

安全改写：

- 需要更多外部结构支持。
- 表达方式容易被误解。
- 情绪回应方式不同。
- 亲密关系中需要学习沟通和表达。
- 这段关系存在节奏差异，需要具体场景里的沟通翻译。

## 5. 禁止玄学化

禁用：

- 前世
- 天命
- 缘分密码
- 千年修得
- 命中注定

安全改写：

- 关系中的底层匹配。
- 沟通节奏。
- 情绪需要。
- 角色互补。
- 关系经营方式。

## 6. 禁止直接照搬老师口语

说明：

老师录音中的现场表达通常带有情境、语气和人工判断，不能直接进入前台产品输出。进入 Report OS 前必须完成：

1. 去除隐私信息。
2. 去除强判断、攻击性或绝对化表达。
3. 改写为倾向、场景和建议。
4. 标注可用等级和置信度。
5. 必要时降级为人工专家参考。

## 7. 关系类安全边界

禁止：

- 你们不合适。
- 这段婚姻一定有问题。
- 他就是不爱你。
- 孩子就是故意对抗你。
- 团队里某个人拖后腿。

安全改写：

- 你们在节奏和需求表达上存在差异。
- 这类冲突需要回到具体场景中拆解。
- 可以先把对方的表达翻译成需求，再讨论行动。
- 团队协作应关注角色匹配和机制设计，而不是成员优劣。

## 8. 儿童和校园类安全边界

禁止：

- 问题孩子。
- 家庭教育失败。
- 老师处理不当。
- 孩子就是不努力。

安全改写：

- 这个行为需要结合年龄、环境和互动方式理解。
- 孩子可能需要更清晰的结构或更具体的回应。
- 家校沟通可以先围绕场景和支持方式展开。

## 9. 低置信度资料输出边界

当资料来自截图、口述、皮纹速测或部分缺失报告时，必须加上低置信度说明：

- 以下内容只作为初步理解，不代表完整测评结论。
- 目前资料不足以生成完整报告，建议补充关键指标。
- 这个判断需要结合更多行为场景验证。

## 10. 输出前检查表

输出前逐项检查：

| 检查项 | 必须结果 |
| --- | --- |
| 是否含医学 / 心理诊断 | 否 |
| 是否含绝对化表达 | 否 |
| 是否含伤害性标签 | 否 |
| 是否玄学化 | 否 |
| 是否直接照搬老师口语 | 否 |
| 是否把“合盘”作为前台主词 | 否 |
| 是否标注低置信度边界 | 是，如资料不足 |
| 是否给出可执行下一步 | 是 |

| --- | --- | --- | --- |

| 一定会 | 绝对化 | 更容易、可能、在某些场景下 | D |
| 绝对 | 绝对化 | 倾向于、需要结合环境看 | D |
| 99%婚姻有问题 | 关系伤害 / 绝对化 | 亲密关系中可能更容易出现沟通节奏差异，需要具体场景拆解 | D |

| 白眼狼 | 伤害性标签 | 情绪回应方式不同，不代表没有感受 | D |
| 懒 | 伤害性标签 | 需要更多外部结构、启动机制或身体参与支持 | D |

可用等级说明：本表等级 D 表示原始表达禁止前台输出；安全改写句可按场景进入 A/B 级输出，但必须结合用户问题和置信度。

## 12. V0.4 行业大会资料安全改写规则

行业大会资料包含行业趋势、脑科学、AI、全生命周期、医养康养、平台化和行业话语权等内容。进入 AIPIWEN 前台表达前，必须降级为辅助理解、场景建议和内部研究方向，不能写成确定性科学结论、医学承诺或宏大叙事。

| 行业大会原始方向 | 风险类型 | 安全改写 | 可用等级 |
| --- | --- | --- | --- |
| 脑科学已经证明某类孩子如何发展 | 科学性夸大 / 儿童定型 | 可结合脑科学相关研究作为长期观察参考，但不能替代对具体孩子的持续观察 | D |
| 指纹科学可以判断疾病或健康风险 | 医学判断 | 皮纹 / 指纹数据只能作为潜能辅助参考，健康问题应以专业医疗评估为准 | D |
| 医养、康养、疾病干预可以成为当前产品能力 | 医疗承诺 | 医养和康养方向仅作为远期研究或内部观察，不作为当前产品承诺 | D |
| 全生命周期养护 | 宏大承诺 / 健康承诺 | 可升级为“不同年龄段的自我理解、沟通和成长支持” | B |
| 生命能量、生命密码、命运轨迹 | 玄学化 | 改写为“个体差异、长期偏好、关系和行动模式” | D |
| AI 可以替代专家完成所有解读 | AI 过度承诺 | AI 用于整理、路由、改写和常见问题解释，复杂判断仍需专家参与 | D |
| AI 永生、数字生命延续 | 玄学化 / 科技夸大 | 改写为“长期问答记录和阶段性成长档案” | D |
| 行业唯一、官方认证第一平台 | 权威背书风险 | 改写为“参与行业交流，持续建设标准化和安全表达能力” | D |
| 家校社协同用于筛查问题孩子 | 未成年人标签 / 校园风险 | 改写为“帮助家校围绕学习方式、沟通方式和支持策略形成共同语言” | D |
| 企业团队画像用于淘汰或筛选人员 | 职场歧视 / 数据滥用 | 改写为“辅助团队理解协作差异和沟通机制，不作为招聘淘汰依据” | D |
| 采集超市 / 共享平台可集中使用用户数据 | 隐私与授权风险 | 必须取得用户授权，做数据最小化、脱敏、访问控制和用途限定 | C |
| 未成年人数据可长期沉淀为成长档案 | 未成年人隐私 | 必须由监护人授权，限制用途、保存期限和可见范围，避免无关传播 | C |
| 指纹科学可以预测未来职业和关系 | 命运预测 / 绝对化 | 改写为“提供职业学习和关系沟通的倾向参考，需要现实验证” | D |
| 行业大会观点可直接用于官网宣传 | 宏大叙事 / 前台失真 | 只能转化为克制的产品定位、合规边界和能力路线，不直接引用高风险原话 | C |

补充规则：

- 涉及脑科学、医学、疾病、康养、医养的表达，一律先进入内部审查，不自动进入前台。
- 涉及学校、班级、未成年人、企业团队的数据，必须优先检查授权、脱敏、用途限定和最小必要原则。
- 官网可表达 AI 报告生成、多视角理解、关系沟通和团队协作，但不能表达诊断、预测、筛查或替代专家。
