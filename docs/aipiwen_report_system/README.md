# AIPIWEN 报告系统知识库底座

## 放什么

本目录用于沉淀 AIPIWEN 报告系统升级所需的本地知识资料、方法论、母模板、案例、话术、AI 规则和风险边界。

## 命名规则

- 文件名使用：`AIPIWEN_主题_V版本.md`
- 原始资料保留来源说明、日期、整理状态。
- 未经核验的资料必须标注「待核验」。

## 不允许放什么

- 不放真实用户隐私资料。
- 不放未脱敏的报告、聊天记录、手机号、微信号。
- 不放 API Key、Cookie、Token、Redis 地址等敏感配置。
- 不放会被前端或 API 自动读取的运行时代码。

## 后续如何使用

本目录先作为本地资料库。后续可以人工选择部分内容进入报告模板升级、Prompt 规则升级和案例库建设，但必须经过人工审阅。
