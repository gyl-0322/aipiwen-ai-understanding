# AIPIWEN 外部机构交付流程参考 V0.1

## 1. 定位

本文件只提炼外部培训资料中对 AIPIWEN 有参考价值的交付流程。它不复制外部机构的商业包装、代理体系、成交话术或课程销售逻辑。

## 3. AIPIWEN 推荐交付流程

1. 用户选择场景：孩子行为、个人理解、关系合看、团队协作、职业学习。
2. 系统确认目的：快速读懂、完整报告、某个行为、关系冲突、职业学习等。
3. 用户可选上传资料：报告只是增强理解，不是使用前提。
4. AI 解析资料：识别指标、主体、关系、年龄、授权和风险。
5. 追问关键上下文：场景、持续时间、后天训练、当前角色和用户不认同点。
6. 生成安全输出：只输出倾向、观察方向和低风险行动建议。
7. 安全改写和风险拦截：医学、心理、命理、绝对化、标签化必须处理。
8. 转人工专家：深度、高风险、重大决策、资料冲突明显时触发。
9. 沉淀知识卡：只沉淀脱敏后的规则、案例模式和安全改写，不沉淀隐私原文。

## 4. 不吸收的交付内容

- 代理招商、机构加盟、课程成交话术。
- “一次解读改变人生”的强承诺表达。
- 把高价咨询包装成 AI 自动结论。
- 用报告做招聘淘汰、升学判断、婚恋裁决。
- 把生命、使命、疾病、心理治疗等内容作为普通前台产品承诺。
