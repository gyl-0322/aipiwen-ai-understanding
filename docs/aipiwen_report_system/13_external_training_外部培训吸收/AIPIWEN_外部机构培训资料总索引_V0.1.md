## 4. 与 V0.2 老师录音的关系

- V0.2 更接近 AIPIWEN 自有老师的报告解读风格，适合作为内部主方法论来源。
- V0.8 更偏行业外部培训和交付现场，适合补充“如何问、如何校正、如何解释行为不一致、如何训练解读师”。
- 当两者冲突时，前台表达以 AIPIWEN 安全边界和 V0.2 内部方法论为主，V0.8 作为补充参考。

## 5. 与 V0.4 行业大会资料的关系

- V0.4 是行业战略层：AI 路线、合规、全生命周期、官网表达。
- V0.8 是训练方法层：行为倒推、后天环境校正、ATD 深解、交付流程。
- V0.4 决定方向，V0.8 补充解读能力，两者都不能绕过安全边界直接进入前台。

## 6. 与 V0.5 / V0.6 / V0.7 的关系

- V0.5 Schema 需要新增 `behavior_only_input`、`user_disagrees_with_report`、`environment_context_required`。
- V0.6 Prompt Pack 需要补充“行为输入先问场景，不从单一行为推断人格类型”。
- V0.7 测试样本未来需要新增“用户说报告不准”“家长只描述行为”“资料不完整但用户要求结论”等反向样本。

## 7. 吸收边界

可吸收：

- 行为倒推和场景拆解。
- 先天倾向与后天环境共同解释当下表现。
- ATD/APD 的速度、角度、温度和压力反应解释框架。
- 报告不一致时的追问和校正流程。
- 解读师训练、人工专家复核、AI 与人工分工。

不可直接吸收：

- 医学、心理、疾病判断。
- 命理化、玄学化、生命使命式确定表达。
- 把孩子、伴侣、员工说成固定类型或问题对象。
- 绝对化职业、升学、关系、团队决策建议。
- 外部机构商业包装、代理招商、课程成交话术。
