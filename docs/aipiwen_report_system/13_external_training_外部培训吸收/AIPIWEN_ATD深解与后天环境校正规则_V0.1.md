# AIPIWEN ATD 深解与后天环境校正规则 V0.1

## 1. 定位

外部培训资料中，ATD/APD 不只被当作“快慢”或“敏感/不敏感”，还被用于解释反应速度、感受角度、压力温度、恢复方式和环境适配。本文件将其转成 AIPIWEN 可用的安全规则。

## 2. 总公式

前台可用表达：

> 先天倾向 + 后天环境 + 当前场景 = 当下表现。

内部执行含义：

- 先天倾向：报告中的相对稳定倾向。
- 后天环境：家庭、学校、职业、训练、关系、文化和长期经历。
- 当前场景：此刻面对的任务、压力、关系对象和身体状态。
- 当下表现：用户看到的行为，不等于完整人格。

## 4. 用户认为报告不准确的处理流程

1. 先确认用户感受：报告如果有不贴近的地方，可以作为校正线索。
2. 确认资料质量：报告是否完整，采集是否清晰，指标是否可读。
3. 定位不一致段落：是性格、学习方式、关系、职业，还是某个具体指标。
4. 追问后天变量：家庭、学校、训练、职业角色、关系阶段、重大经历。
5. 区分三类情况：资料缺失、用户当前状态变化、报告表达过度。
6. 降低置信度：从完整结论降为“可能方向 + 追问 + 观察动作”。
7. 必要时建议人工专家复核。

## 5. 前台安全表达

可用：

- “这个指标更适合帮助你理解反应节奏。”
- “这不是判断好坏，而是看在哪些场景更省力或更费力。”
- “如果你觉得不像，我们先看是不是后天训练或当前角色改变了外在表现。”
- “报告只能作为理解参考，不能替代你真实生活中的观察。”

禁用：

- “这是你真正的命。”
- “报告一定比你更懂你。”
- “你这个数值会导致某种疾病。”
- “你天生不适合某类关系/职业/学习。”
