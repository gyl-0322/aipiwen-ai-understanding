# AIPIWEN 行为倒推与场景解读规则 V0.1

## 1. 定位

行为倒推不是“看见一个行为就判断一个人”。它的正确用法是：先描述用户看到的具体场景，再把可能的底层差异、后天环境和当前压力分开，最后给低风险行动建议。

## 2. 总规则

1. 先问场景，不先下结论。
2. 先拆行为，不先贴标签。
3. 先看持续时间、频率和影响范围，再判断输出深度。
4. 有报告时用报告做辅助理解，没有报告时只做观察方向。
5. 涉及身体症状、长期情绪困扰、自伤暴力、医学心理诊断时，立即降级并建议专业支持。

## 4. 输出结构

当用户只给行为，不给完整报告时，输出顺序必须为：

1. 复述行为场景。
2. 说明单一行为不能直接判断人格或类型。
3. 给 2-3 个可能方向。
4. 提 1-3 个追问。
5. 给一个低风险观察动作。
6. 说明何时需要补充报告或人工专家。
