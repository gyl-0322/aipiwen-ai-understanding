# AIPIWEN 与外部机构差异化定位 V0.1

## 1. 定位

V0.8 的目标不是复制外部机构，而是吸收其成熟解读训练中的可复用方法，再转化为 AIPIWEN 自己的 AI 报告生成能力、安全话术能力和多场景行为理解能力。

## 2. 外部机构常见路径

| 路径 | 特征 | AIPIWEN 是否复制 |
| --- | --- | --- |
| 测评采集 -> 老师解读 | 依赖人工经验，现场感强 | 不复制人力依赖，吸收追问和校正逻辑 |
| 报告解读 -> 课程/咨询 | 通过深度服务提高客单价 | 不复制成交话术，保留专家服务入口 |
| 指导师培训 -> 认证 | 通过培训扩大服务人员 | 不复制认证包装，建立内部审核 SOP |
| 沙龙/线下活动 | 适合家长教育和信任建立 | 可做低敏感科普，不做诊断式宣传 |
| 代理/机构合作 | 依赖渠道扩张 | 不作为 Report OS 主线 |

## 3. AIPIWEN 差异化主线

| direction_id | AIPIWEN 主线 | 与外部机构的区别 | 对产品的意义 |
| --- | --- | --- | --- |
| DIFF-001 | AI 报告生成能力 | 从人工口述转为结构化、可复用、可测试的报告生成 | 支撑上传报告、个人完整、关系合看和团队报告 |
| DIFF-002 | 安全话术能力 | 不照搬现场强判断，统一做安全改写 | 降低医学、心理、标签和绝对化风险 |
| DIFF-003 | 场景化行为理解 | 用户可以先说行为，不必须先买测评 | 增强孩子行为、亲子、学习场景入口 |
| DIFF-004 | 多视角关系解释 | 从单人报告扩展为亲子、亲密、合伙、团队互动循环 | 支撑 V0.3 关系合看结构 |
| DIFF-005 | 专家 + AI 协作 | AI 做低风险整理，专家处理复杂和高风险 | 保留高价值服务，不让 AI 过度承诺 |
| DIFF-006 | 可持续知识库和 Prompt 体系 | 把经验沉淀成 Schema、Prompt、测试样本 | 让能力可迭代、可验收、可回归测试 |
| DIFF-007 | 可复用行业内容资产 | 从单次解读转成方法论、案例、规则、拦截词表 | 支撑长期产品化 |
| DIFF-008 | 低敏感公共表达 | 避免玄学化、医学化、夸张化 | 适合官网、学校、企业和未成年人场景 |

## 4. AIPIWEN 不做什么

- 不做玄学化解释。
- 不做单次报告生意。
- 不做只卖测评。
- 不做纯代理招商。
- 不做 AI 替代专家。
- 不做职业、婚恋、升学、医学和心理的确定结论。
- 不把未成年人、伴侣、员工做成标签或排名对象。

## 5. AIPIWEN 要做什么

- 做 AI 个体差异理解与报告生成系统。
- 做上传报告兼容和多视角解读。
- 做行为输入到场景追问的理解助手。
- 做亲子、亲密、合伙人、团队的差异翻译。
- 做安全边界、降级输出和人工专家协作。
- 做 Report OS 知识库、Schema、Prompt Pack 和测试样本的持续迭代。

## 6. 对官网和商业表达的影响

前台主张应从“我们测得很准”转为：

- “把已有报告转成可理解、可行动、可沟通的建议。”
- “先看你遇到的场景，再决定是否需要上传报告。”
- “AI 做资料整理和低风险解释，复杂问题交给人工专家复核。”
- “报告只作为理解参考，不替代医学、心理、教育、职业或法律专业判断。”
