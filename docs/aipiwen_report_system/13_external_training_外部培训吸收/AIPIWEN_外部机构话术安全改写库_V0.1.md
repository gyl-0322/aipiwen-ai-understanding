# AIPIWEN 外部机构话术安全改写库 V0.1

## 1. 定位

外部培训资料中存在大量现场口语、行业内部话术、夸张表达和高风险判断。本文件只保留“风险类型 -> AIPIWEN 安全改写”的规则，不把原话直接进入前台。

## 3. 风险等级映射

| 风险类型 | 默认风险等级 | 系统动作 |
| --- | --- | --- |
| 医学诊断、心理诊断、用药建议 | R3 | 拒绝诊断，建议专业支持 |
| 自伤、暴力、严重情绪困扰 | R3 | 不输出普通报告，转专业帮助 |
| 未成年人标签化 | R2 | 安全改写，限制输出 |
| 关系、职业、升学决定论 | R2 | 降级为探索建议 |
| 命理化、玄学化、绝对化 | R2 | 改写为倾向和参考 |
| 企业淘汰、排名、筛选 | R2/R3 | 限制或拒绝 |
| 轻度口语夸张 | R1 | 安全改写后可用 |

## 4. Prompt 使用要求

生成任何前台内容前必须检查：

- 是否把行为等同于人格。
- 是否把指标等同于疾病或心理问题。
- 是否把报告等同于命运、职业、婚恋或升学结论。
- 是否使用了羞辱性、评判性、恐吓性或成交型表达。
- 是否遗漏了“报告只是辅助理解参考”的边界。
