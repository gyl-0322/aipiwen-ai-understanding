# AIPIWEN 指标本体库 V0.1

## 1. 使用边界

指标本体用于统一报告库中的解释口径。任何单一指标都不能单独决定人格、能力、职业、关系结果或亲子结论，必须结合用户问题、年龄阶段、场景和其他指标综合解释。

每个指标条目包含：一句话解释、它不代表什么、适用场景、可用表达、禁用表达、可进入哪些报告、可调用案例。

## 2. TRC

- 一句话解释：TRC 用于理解一个人接收和处理信息时的节奏、容量和注意力使用方式。
- 它不代表什么：不代表聪明或不聪明，也不代表学习一定好或一定差。
- 适用场景：学习方式、任务安排、沟通节奏、团队会议、亲子陪伴。
- 可用表达：更适合有节奏切换的任务安排；需要用合适方式维持注意力。
- 禁用表达：注意力有问题；坐不住就是不认真；TRC 高一定更优秀。
- 可进入报告：快速读懂、个人完整、孩子行为、亲子合看、亲密关系合看、团队协作。
- 可调用案例：高 TRC 孩子写作业听音乐；高 TRC 兴趣班先体验。

## 3. ATD / APD / 敏感值

- 一句话解释：ATD / APD / 敏感值用于理解反应速度、感受强度和压力下的节奏变化。
- 它不代表什么：不代表情绪有病，不代表抗压能力绝对高低。
- 适用场景：情绪回应、冲突处理、决策节奏、亲密关系、亲子安抚。
- 可用表达：在压力场景下更需要缓冲时间；对环境变化更敏锐。
- 禁用表达：玻璃心；心理疾病；一定扛不住压力；抑郁体质。
- 可进入报告：个人完整、孩子行为、亲子合看、亲密关系合看、团队协作。
- 可调用案例：敏感孩子“肚子疼”需要先安慰；体觉感受高需要陪伴和在场感。

## 4. 性格类型

### 4.1 认知型

- 一句话解释：偏向先理解规则和逻辑，再进入行动。
- 它不代表什么：不代表冷漠或不合群。
- 适用场景：学习解释、任务拆解、沟通确认。
- 可用表达：先讲清楚为什么，再给步骤。
- 禁用表达：想太多；不听话。
- 可进入报告：个人完整、孩子行为、关系合看、团队协作。
- 可调用案例：嘴答应了但脑子没进去，需要复述指令。

### 4.2 模仿型

- 一句话解释：偏向通过示范、跟随和重复建立理解。
- 它不代表什么：不代表没有创造力。
- 适用场景：技能学习、亲子陪伴、团队带教。
- 可用表达：给他看一遍，比讲十遍更有效。
- 禁用表达：只会照抄；没主见。
- 可进入报告：个人完整、孩子行为、亲子合看、团队协作。
- 可调用案例：学习通道与示范型任务安排。

### 4.3 开放型

- 一句话解释：偏向从环境、兴趣和新鲜感中获得动力。
- 它不代表什么：不代表散漫或不稳定。
- 适用场景：兴趣选择、探索学习、创新任务。
- 可用表达：先给体验，再逐步收束选择。
- 禁用表达：三分钟热度；不能坚持。
- 可进入报告：个人完整、孩子行为、亲子合看、团队协作。
- 可调用案例：高 TRC 兴趣班先体验，不要一次报长期。

### 4.4 逆思型

- 一句话解释：偏向先看到风险、漏洞或不同路径。
- 它不代表什么：不代表故意对抗或推责。
- 适用场景：风险识别、规则沟通、冲突理解。
- 可用表达：他可能是在先确认边界和风险。
- 禁用表达：叛逆；唱反调；管得越紧越该压住。
- 可进入报告：孩子行为、亲子合看、亲密关系合看、团队协作。
- 可调用案例：逆思型杯子案例；管得越紧越反抗。

### 4.5 超级认知型

- 一句话解释：偏向从更高层次理解意义、目标和人生方向。
- 它不代表什么：不代表天生高人一等。
- 适用场景：目标建立、导师陪伴、长期规划。
- 可用表达：需要能对话意义和方向的人陪他走。
- 禁用表达：天才命；注定成功。
- 可进入报告：个人完整、孩子行为、亲子合看。
- 可调用案例：超级认知孩子需要人生导师。

### 4.6 完美型

- 一句话解释：偏向重视标准、质量和完成度。
- 它不代表什么：不代表难相处或强迫。
- 适用场景：任务交付、反馈方式、学习要求。
- 可用表达：明确标准和阶段性完成线会更稳定。
- 禁用表达：强迫症；太挑剔。
- 可进入报告：个人完整、关系合看、团队协作。
- 可调用案例：待补充。

### 4.7 整合型

- 一句话解释：偏向综合多方信息后再判断。
- 它不代表什么：不代表没有立场。
- 适用场景：复杂决策、协作协调、关系沟通。
- 可用表达：适合担任信息整合和协调角色。
- 禁用表达：和稀泥；没主见。
- 可进入报告：个人完整、关系合看、团队协作。
- 可调用案例：视觉辨识低 + 听觉感受高，决策时要多验证。

### 4.8 双极型 / 双击型

- 一句话解释：该名称存在口径不稳定，暂作为内部待审术语。
- 它不代表什么：不代表医学意义上的双相或心理疾病。
- 适用场景：仅供内部专家复核。
- 可用表达：内部待审，不进入前台自动输出。
- 禁用表达：双相；人格分裂；心理疾病。
- 可进入报告：暂不进入前台报告。
- 可调用案例：待补充。

## 5. 学习通道

### 5.1 听觉

- 一句话解释：通过声音、语言、问答和复述处理信息的偏好。
- 它不代表什么：不代表只靠听就能学会。
- 适用场景：课堂、沟通、指令传达、客户讲解。
- 可用表达：用问答和复述确认，比长篇灌输更有效。
- 禁用表达：听不进去就是不用心。
- 可进入报告：个人完整、孩子行为、关系合看、团队协作。
- 可调用案例：听觉辨识低的客户，不要长篇讲，要“你问我答”。

### 5.2 视觉

- 一句话解释：通过画面、结构、图表和可见线索处理信息的偏好。
- 它不代表什么：不代表只看图不听讲。
- 适用场景：学习计划、工作看板、关系沟通、团队协作。
- 可用表达：把信息可视化后更容易判断。
- 禁用表达：看不懂就是能力差。
- 可进入报告：个人完整、孩子行为、关系合看、团队协作。
- 可调用案例：视觉辨识低 + 听觉感受高，决策时要多验证。

### 5.3 体觉

- 一句话解释：通过身体感受、动作、触摸和真实体验处理信息的偏好。
- 它不代表什么：不代表只爱玩或不爱学习。
- 适用场景：幼儿和儿童学习、运动、亲密关系、压力恢复。
- 可用表达：通过动手、运动和真实体验更容易进入状态。
- 禁用表达：坐不住；没规矩。
- 可进入报告：个人完整、孩子行为、亲子合看、亲密关系合看。
- 可调用案例：体觉型孩子适合户外、运动、玩水、拼搭；体觉感受高需要陪伴。

## 6. 行为模式

### 6.1 动机型

- 一句话解释：更容易被目标、意义、竞争或外部激励启动。
- 它不代表什么：不代表功利或只看结果。
- 适用场景：学习启动、职业建议、团队激励。
- 可用表达：先建立目标和反馈，再安排执行。
- 禁用表达：没目标就是废。
- 可进入报告：个人完整、孩子行为、团队协作。
- 可调用案例：精神功能双低需要外部目标或梦想启动。

### 6.2 构思型

- 一句话解释：更容易从想法、方案和可能性中启动。
- 它不代表什么：不代表只会想不会做。
- 适用场景：创意任务、职业方向、团队角色。
- 可用表达：给他构思空间，再设置落地节点。
- 禁用表达：空想家。
- 可进入报告：个人完整、团队协作、关系合看。
- 可调用案例：成人职业过渡案例。

### 6.3 均衡型

- 一句话解释：在目标、想法和执行之间相对平衡。
- 它不代表什么：不代表没有特点。
- 适用场景：岗位适配、学习策略、协作分工。
- 可用表达：适合在稳定结构中持续推进。
- 禁用表达：普通；没天赋。
- 可进入报告：个人完整、团队协作。
- 可调用案例：待补充。

## 7. 左右脑底色

- 一句话解释：用于理解信息处理、表达和行动的基础偏好。
- 它不代表什么：不代表左右脑优劣，也不代表能力上限。
- 适用场景：学习方式、沟通风格、职业方向、团队分工。
- 可用表达：更习惯先整体感受或先拆解逻辑。
- 禁用表达：左脑好、右脑差；天生不适合。
- 可进入报告：快速读懂、个人完整、关系合看、团队协作。
- 可调用案例：成人职业过渡案例、亲子沟通场景。

## 8. 五大功能区

### 8.1 精神功能

- 一句话解释：与目标、愿景、意义感和启动方向有关。
- 它不代表什么：不代表道德高低或意志强弱。
- 适用场景：目标建立、职业方向、学习动力。
- 可用表达：需要外部目标或梦想来启动。
- 禁用表达：没理想；没出息。
- 可进入报告：个人完整、孩子行为、团队协作。
- 可调用案例：精神功能双低不等于没能力。

### 8.2 思维功能

- 一句话解释：与理解、分析、判断和结构化能力有关。
- 它不代表什么：不代表聪明或笨。
- 适用场景：学习策略、任务拆解、团队决策。
- 可用表达：适合用结构和逻辑帮助进入任务。
- 禁用表达：脑子不行。
- 可进入报告：个人完整、关系合看、团队协作。
- 可调用案例：嘴答应了但脑子没进去，需要复述指令。

### 8.3 体觉功能

- 一句话解释：与身体感受、行动体验和真实在场有关。
- 它不代表什么：不代表懒散或只重感官。
- 适用场景：儿童学习、运动、亲密关系、压力恢复。
- 可用表达：真实陪伴和身体参与会更有效。
- 禁用表达：贪玩；矫情。
- 可进入报告：个人完整、孩子行为、亲子合看、亲密关系合看。
- 可调用案例：体觉型孩子适合户外、运动、玩水、拼搭。

### 8.4 听觉功能

- 一句话解释：与语言、声音、倾听、问答和表达反馈有关。
- 它不代表什么：不代表口才好坏。
- 适用场景：亲子指令、客户沟通、团队会议。
- 可用表达：用短句、问答和复述更容易确认理解。
- 禁用表达：说了也白说。
- 可进入报告：个人完整、孩子行为、关系合看、团队协作。
- 可调用案例：听觉辨识低的客户，不要长篇讲。

### 8.5 视觉功能

- 一句话解释：与图像、结构、观察、空间和可视化判断有关。
- 它不代表什么：不代表审美或成绩。
- 适用场景：学习材料、工作看板、决策验证。
- 可用表达：把任务和选择看见，会更容易判断。
- 禁用表达：看不懂就是差。
- 可进入报告：个人完整、孩子行为、关系合看、团队协作。
- 可调用案例：视觉辨识低 + 听觉感受高，决策时要多验证。

## 9. V0.2 真实录音增补：五大功能区生活化细分

### 9.1 精神功能

- 细分解释：与目标感、学习动力、愿景和方向有关；左侧更偏团队、事业和对外价值，右侧更偏个人、家庭和自我驱动。
- 它不代表什么：双低不等于没能力；高目标也不代表一定成功。
- 前台可用：如果目标感不稳定，可以用外部目标、榜样或短周期反馈帮助启动。
- 内部参考：精神功能高的人可能目标多、压力大，需要区分愿景和落地。
- 禁用表达：没目标就是没出息；双低就是懒；高目标一定能成。

### 9.2 思维功能

- 细分解释：包含语言逻辑和空间心像。语言逻辑偏表达、说服、包装；空间心像偏规划、想象、创造和从无到有。
- 它不代表什么：思维功能低不代表笨，表达慢也不代表没想法。
- 前台可用：嘴快脑慢时，用复述指令确认；想得多说不清时，用思维导图辅助表达。
- 内部参考：思维功能组合差异会影响亲密沟通、任务反馈和孩子指令接收。
- 禁用表达：脑子不行；说话不算数；嘴快就是敷衍。

### 9.3 体觉功能

- 细分解释：体觉辨识偏执行力、行动力、动手能力；体觉感受偏身体感受、环境要求、在场感和肢体接触。
- 它不代表什么：执行慢不代表没有执行力；体觉感受高不代表矫情。
- 前台可用：体觉型孩子可通过运动、户外、玩水、拼搭进入学习；亲密关系中体觉感受高的人更需要陪伴和在场。
- 内部参考：体觉感受高低差异容易影响亲密关系中的陪伴需求。
- 禁用表达：懒、贪玩、黏人、矫情。

### 9.4 听觉功能

- 细分解释：听觉辨识偏听内容、抓重点；听觉感受偏听语气、语调、节奏、旋律。
- 它不代表什么：听觉辨识低不代表听不懂，而是可能选择性接收重点。
- 前台可用：听觉辨识低的用户，不适合长篇讲解，适合“你问我答”和每次确认一个重点。
- 内部参考：听觉感受高的人可能更容易被语气影响。
- 禁用表达：你根本不听；理解力差；讲了也没用。

### 9.5 视觉功能

- 细分解释：视觉辨识偏识人识事、观察判断；视觉感受偏审美、色彩、画面和风格偏好。
- 它不代表什么：视觉辨识低不代表没判断力，视觉感受高不代表一定适合艺术职业。
- 前台可用：视觉辨识低 + 听觉感受高时，重大决策前要写下来、看证据、留冷静期。
- 内部参考：兴趣班选择可看视觉感受、空间心像和体觉辨识组合。
- 禁用表达：容易被骗、没眼光、一定适合画画。
