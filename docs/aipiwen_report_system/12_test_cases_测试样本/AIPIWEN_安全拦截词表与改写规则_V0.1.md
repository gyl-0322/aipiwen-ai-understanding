# AIPIWEN 安全拦截词表与改写规则 V0.1

## 1. 使用说明

本词表用于上传报告解析、Prompt 输出前安全改写和人工验收。命中词不等于一定拒绝；系统需结合上下文判断风险等级，并执行 rewrite / limit / refuse / refer_human / suggest_professional_help。

## 3. 输出前改写规则

1. 命中 R3 词且用户要求结论时，禁止普通报告输出。
2. 命中医学/心理、自伤、暴力、法律、财务时，优先专业帮助建议。
3. 命中未成年人标签时，必须改为年龄、场景、环境和支持方式。
4. 命中关系决定论时，必须改为差异、误解、需求、行动。
5. 命中企业/学校高风险时，只允许群体、机制和支持策略，不输出个体评价。

## 4. 安全改写示例

| 原始表达 | 安全改写 |
| --- | --- |
| 这个孩子没救了 | 这个行为需要结合年龄、环境和支持方式理解，目前不适合做定性判断 |
| 他们一定会离婚 | 这段关系可能在某些场景下更容易出现误解，需要回到具体互动中拆解 |
| 这个员工应该淘汰 | 团队报告不能用于淘汰，只能用于优化协作机制和分工 |
| 报告能看出疾病风险 | 疾病和健康问题应以专业医疗评估为准，报告只作理解参考 |
