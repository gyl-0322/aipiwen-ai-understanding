## 3. 通用关系报告结构

1. 关系说明：本报告用于理解差异，不用于判断谁对谁错。
2. 双方或多方底色：分别说明核心节奏和表达方式。
3. 关键差异：TRC、ATD、性格、学习通道、行为模式、五大功能区。
4. 常见误解：把差异翻译成具体场景。
5. 冲突机制：说明冲突如何被触发。
6. 互补可能：说明差异如何变成配合。
7. 沟通翻译：把对方语言翻译成可理解需求。
8. 行动计划：给 7 天、30 天或 90 天的具体动作。
9. 边界说明：不诊断、不劝分、不劝合、不做优劣排序。

## 8. 共同维度顺序

关系模板统一按以下顺序组织：

1. TRC：信息和任务节奏。
2. ATD：情绪、反应和压力节奏。
3. 性格类型：表达方式和理解路径。
4. 学习通道：沟通和接收信息方式。
5. 行为模式：启动、构思和执行方式。
6. 五大功能区：精神、思维、体觉、听觉、视觉的互补与冲突。

## 9. 差异到行动的结构

关系报告必须使用：

差异 -> 冲突 -> 互补 -> 行动计划

示例结构：

| 步骤 | 输出方式 |
| --- | --- |
| 差异 | 你们在信息节奏上不同 |
| 冲突 | 一方觉得对方太快，另一方觉得对方拖延 |
| 互补 | 快节奏方可推动进度，慢节奏方可检查风险 |
| 行动计划 | 会议前先发资料，会议中分出决策和复核角色 |

## 10. 可复用章节标题

- 这不是谁的问题，而是节奏差异。
- 你以为的拒绝，可能是对方需要缓冲。
- 把差异变成分工，而不是变成指责。
- 先翻译需求，再讨论做法。
- 本周先改一个互动动作。

## 14. V0.3 四类关系报告结构

### 14.1 亲密关系合看报告

1. 关系说明：不劝分、不劝合，只看差异和互动方式。
2. 双方底色：分别说明 TRC、ATD、性格类型和沟通通道。
3. 核心画像：这段关系最容易卡住的互动循环。
4. 差异对照：节奏、情绪、表达、陪伴、决策。
5. 冲突场景：列出最容易误解的 3 个场景。
6. 互补方式：把快慢、感受、逻辑、执行差异转成分工。
7. 沟通翻译：把指责句改写成需求句。
8. 行动计划：7 天修复动作 + 30 天沟通机制。
9. 边界说明：关系选择需结合真实互动、价值观和现实责任。

### 14.2 亲子关系合看报告

1. 关系说明：不判断孩子，不诊断家庭，不评价老师。
2. 孩子底色：孩子的信息节奏、情绪节奏、学习通道和行为模式。
3. 家长底色：家长的控制方式、反应速度、表达方式和期待来源。
4. 误解场景：学习、作业、兴趣班、情绪、分享、规则。
5. 冲突循环：家长越急 -> 孩子越躲或越顶 -> 家长更控制。
6. 沟通翻译：把孩子行为翻译成需求，把家长期待翻译成边界。
7. 陪伴建议：本周 3 个小动作。
8. 升级提醒：长期影响睡眠、情绪、学习或生活时，建议专业支持。

### 14.3 合伙人关系合看报告

1. 合伙说明：只用于协作理解，不用于判断能不能合作。
2. 双方角色底色：机会识别、风险识别、决策节奏、执行方式。
3. 权责结构：谁适合定方向、谁适合补漏洞、谁适合推进落地。
4. 冲突场景：钱、权、决策、节奏、责任、外部沟通。
5. 互补设计：把差异转成明确分工和复核机制。
6. 沟通机制：会议节奏、记录规则、决策截止时间、反悔规则。
7. 30 天行动计划：先改一个决策机制和一个责任边界。

### 14.4 团队协作理解报告

1. 团队说明书：用于协作设计，不用于招聘淘汰。
2. 团队整体画像：TRC 节奏、ATD 情绪/决策节奏、左右脑结构。
3. 角色分布：决策者、执行者、创意者、关系协调者。
4. 能力地图：精神、思维、体觉、听觉、视觉功能分布。
5. 协作冲突矩阵：节奏、表达、责任、执行、审美、目标。
6. 会议机制：会前资料、会中角色、会后复盘。
7. 分工建议：岗位适配只做参考，不做优劣排序。
8. 90 天行动建议：先优化沟通、决策和反馈机制。

## 16. V0.3 关系冲突矩阵

| 冲突类型 | 表面冲突 | 底层差异 | 常见误判 | AIPIWEN 安全解释 | 沟通翻译 | 行动建议 |
| --- | --- | --- | --- | --- | --- | --- |
| 节奏冲突 | 你太散 / 你太死板 | TRC 信息节奏不同 | 不认真 / 不灵活 | 处理任务的节奏不同 | 我需要你告诉我什么时候切换、什么时候稳定 | 设任务节点和自由区间 |
| 情绪冲突 | 你不在乎我 / 你太情绪化 | ATD 恢复节奏不同 | 冷漠 / 玻璃心 | 情绪回应速度不同 | 我需要先被回应，再慢慢讲道理 | 先回应，再复盘 |
| 表达冲突 | 你太啰嗦 / 你说不清 | 思维功能和听觉通道不同 | 没重点 / 没逻辑 | 信息组织方式不同 | 我需要你先说结论，再补原因 | 用三句话结构 |
| 控制冲突 | 你总管我 / 你不负责 | 认知、逆思、边界需求不同 | 叛逆 / 不自律 | 对规则和自主权的需求不同 | 我需要边界，也需要选择权 | 给选项和责任 |
| 陪伴冲突 | 你不陪我 / 你太黏我 | 体觉感受和关系安全感不同 | 不爱 / 依赖 | 在场感需求不同 | 我需要确认你在这里 | 设固定陪伴时间 |
| 决策冲突 | 你太快 / 你太犹豫 | 视觉辨识、风险识别、ATD 不同 | 冲动 / 拖延 | 决策证据和速度不同 | 我需要证据，也需要截止时间 | 决策清单 + 截止点 |
| 目标冲突 | 你不顾家 / 你不支持我 | 精神功能左右侧和角色目标不同 | 自私 / 没上进 | 家庭与事业目标排序不同 | 我需要被纳入你的计划 | 月度目标对齐 |
| 责任冲突 | 都是你没做好 | 行为模式和执行边界不清 | 推责 | 责任没有被具体拆分 | 我们先确认谁负责哪一步 | 写清 RACI |
| 执行冲突 | 你光说不做 / 你只会催 | 体觉辨识、行为模式不同 | 懒 / 急躁 | 启动和落地速度不同 | 我需要更明确的下一步 | 每次只定一个动作 |
| 审美 / 细节冲突 | 你怎么总看错 | 视觉辨识、视觉感受差异 | 没眼光 / 太挑 | 观察和审美标准不同 | 我需要你说明判断依据 | 用样例对齐标准 |

## 17. V0.3 关系报告降级规则

| 资料状态 | 允许输出 | 禁止输出 |
| --- | --- | --- |
| 只有一方报告 | 单方关系模式参考、可能的沟通盲点 | 双方关系结论、对另一方画像 |
| 双方都有完整报告 | 关系合看报告、指标对照、冲突矩阵、行动计划 | 绝对化关系判断 |
| 多人团队资料不足 | 团队协作观察建议、低置信度角色假设 | 团队完整能力地图和岗位结论 |
| 没有完整指标 | 低置信度建议、补充资料清单 | 正式完整关系报告 |
| 用户只描述行为 | 转入行为理解板块，输出场景解释和回应建议 | 当作测评结论 |

关系报告生成前必须追问：

1. 这段关系类型是什么：亲密、亲子、合伙人、团队。
2. 用户最想解决的具体冲突是什么。
3. 是否双方 / 多方都同意使用资料。
4. 当前资料是否完整，是否缺 TRC、ATD、性格、学习通道、行为模式、五大功能区。
5. 用户希望输出快速版、完整版还是行动计划版。

## 18. V0.3 关系报告安全边界

禁用：

- 你们不合适。
- 你们一定会分开。
- 这个孩子就是被家长毁了。
- 这个合伙人不能合作。
- 婚姻一定有问题。
- 注定冲突。
- 天生相克。
- 合盘注定。

安全表达：

- 你们在某些场景下更容易发生误解。
- 这段关系需要更明确的沟通和边界。
- 当前资料只能提示倾向，不代表结论。
- 是否继续关系需要结合真实互动、价值观、责任和现实选择。
