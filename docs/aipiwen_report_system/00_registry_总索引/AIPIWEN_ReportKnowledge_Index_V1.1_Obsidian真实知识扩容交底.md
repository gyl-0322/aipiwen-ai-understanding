## 1. 本轮定位

本轮不是重做报告模板，也不是改前台页面。

目标是让现有正式报告生成链路在保持当前报告框架的前提下，能检索到更多来自 Report OS / Obsidian / 老师解读资料的后台知识素材。

核心原则：

- 报告结构不动。
- `report-upload.html` 不动。
- PDF 与支付墙不动。
- `api/generate-report.js` 当前接入方式不动。
- 只扩容 `data/report-knowledge-index/report-knowledge-index-v1.json`。
- 检索失败时仍使用现有 `SYSTEM_PROMPT + engineResult + selectedIssues + 硬编码规则` 兜底。

## 4. 本轮重点修正的问题

### 4.1 五大功能区

修正重点：

- 不再把两根手指相加后和个人均值比较。
- 每个功能区按两根手指分别解释。
- 每根手指分别与个人均值比较。
- 再解释左右差异：哪一侧更容易先被调动，哪一侧需要环境支持。

覆盖：

- 精神功能：右拇 / 左拇
- 思维功能：右食 / 左食
- 体觉功能：右中 / 左中
- 听觉功能：右无名 / 左无名
- 视觉功能：右小 / 左小

### 4.2 年龄阶段问题库

修正重点：

- 幼儿、小学、初中、高中、大学/刚毕业、成人、40+ 不共用同一批问题。
- 成年人报告不得出现“孩子/家长”错位称谓。
- 高中选科、升学、考试压力必须保守表达。
- 成人职业与自我理解必须用本人视角。

### 4.3 用户四问差异化回答

修正重点：

- 四个问题不能只替换标题，正文套同一段。
- 不强制所有问题都用三段式。
- 行为类可以三卡。
- 学习类可以“总判断 + 观察清单 + 下一步试法”。
- 重大决策类先做边界，再给可参考维度。
- 心理/医学、关系去留、录用筛选、升学保证只允许降级或转人工。

### 4.4 称谓与年龄

修正重点：

- 严正申明和固定模块必须先看年龄与报告对象。
- 未成年人可以写“孩子/家长”。
- 成年人必须写“你/本人/当前阶段”。
- 成年人报告禁止出现“您孩子”。
