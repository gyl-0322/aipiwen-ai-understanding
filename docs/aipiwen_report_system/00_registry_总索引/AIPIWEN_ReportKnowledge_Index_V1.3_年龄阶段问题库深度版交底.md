# AIPIWEN Report Knowledge Index V1.3 年龄阶段问题库深度版交底

状态：后台知识资产扩容  
日期：2026-07-07  
范围：只扩容 Report Knowledge Index，不修改网站结构、不修改报告页面、不修改 PDF、不修改支付、不部署。

## 1. 本轮定位

V1.3 不是改前台问题选择页，也不是改报告模板。

它的目标是把“不同年龄阶段的问题库、称谓规则、风险边界和回答方向”整理成可检索知识卡，让正式报告生成时能按年龄命中更准确的素材。

## 2. 为什么要做 V1.3

此前报告曾出现两个明显问题：

1. 不同年龄段看到的问题过于相似。
2. 成年人报告里偶尔出现孩子/家长称谓错位。

这些问题本质上不是页面样式问题，而是后台知识索引没有把年龄阶段拆细。

V1.3 的目标是让系统在生成前能检索到：

```text
年龄阶段
用户原话
常见问题
适合输出方向
禁止方向
称谓规则
风险等级
```

## 5. 年龄段核心规则

### 5.1 幼儿 3-6

重点：

- 分离
- 规则感
- 情绪表达
- 身体控制

表达原则：

- 温柔、少指标、多场景。
- 看见孩子正在学习表达和控制。
- 不说叛逆、心理问题、ADHD。

### 5.2 小学 7-12

重点：

- 作业
- 阅读
- 专注
- 学习习惯
- 同伴关系

表达原则：

- 拖拉先看启动困难和任务颗粒度。
- 阅读先看学习通道。
- 同伴冲突先看边界表达和冲突复盘。
- 不说懒、脾气差、不认真。

### 5.3 初中 13-15

重点：

- 青春期边界
- 顶嘴
- 同伴
- 手机
- 学习动力

表达原则：

- 顶嘴不是孩子变坏，而是边界和表达在长出来。
- 手机和游戏先做规则共创，不做成瘾诊断。
- 考试压力要保守表达。

### 5.4 高中 16-18

重点：

- 选科
- 偏科
- 升学
- 考试压力
- 自我认同

表达原则：

- 只给观察维度，不给升学/专业保证。
- 压力持续影响睡眠、生活或学习时，建议专业支持。
- 不判断谁对谁错。

### 5.5 大学 / 刚毕业 19-25

重点：

- 专业
- 职业探索
- 独立生活
- 关系
- 自我状态

表达原则：

- 用本人视角。
- 给能力线索、现实约束和低风险试错。
- 不替用户决定考研、就业、转专业或关系去留。

### 5.6 职场 / 成家育儿 26-40

重点：

- 职业瓶颈
- 团队角色
- 育儿压力
- 伴侣沟通
- 原生家庭

表达原则：

- 职业类只给观察维度和低风险试错。
- 家庭类先拆具体场景，不判谁对谁错。
- 不制造家长内疚。

### 5.7 人生中场 40+

重点：

- 转型
- 带教
- 家庭责任
- 价值感
- 空巢和照护

表达原则：

- 尊重经验，强调经验复用。
- 不写命苦、劳碌命、来不及。
- 健康焦虑和持续低落要降级承接。

## 6. 称谓规则

新增 `RKI-V1.3-AGE-TITLE-VOICE`，用于防止报告称谓错位。

规则：

- 3-18 岁：可用孩子 / 家长视角。
- 19 岁以上：必须用你 / 本人 / 当前阶段。
- 成年人报告不得出现“您孩子”。
- 幼儿报告不得出现职场、升学、职业转型问题。
- 高中报告可以兼顾家长和考生本人，但不能像幼儿段一样说话。
