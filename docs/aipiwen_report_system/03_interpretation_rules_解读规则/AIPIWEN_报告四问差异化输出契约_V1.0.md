# AIPIWEN 报告四问差异化输出契约 V1.0

## 1. 适用范围

本契约只约束用户在报告生成前选择或自行输入的问题回答，不改变正式报告的固定模块、模块顺序、五大功能区、数据总览或 PDF 版式。

## 2. 固定原则

1. 每个问题必须单独分类、单独生成、单独校验。
2. 问题回答允许两张或三张卡片，不强制统一段数。
3. 卡片标题必须根据问题类型变化，不得全部退回“为什么会这样 / 怎么应对 / 未来可期”。
4. 年龄阶段、报告数据、问题原文和现实场景共同参与回答；不能只替换问题标题。
5. 四个不同问题不得共用同一组正文；高度相似时必须使用对应问题类型的安全兜底。
6. 网页报告和 PDF 必须使用后端返回的同一组 `answerCards`。
7. 自定义问题与预设问题执行同一套分类、安全和重复度校验。

## 3. 问题类型与回答模式

|问题类型|回答模式|卡片数量|标题示例|
|-|-|-|-|
|文理 / 选科方向|学习方向验证|2|先看哪种学习入口更顺；用真实科目表现来验证|
|偏科 / 学习方法|学习环节诊断|3|先找真正卡住的环节；换一种入口试一周；用变化校正方法|
|拖拉 / 内驱力|行为拆解|3|这不只是“不想做”；先从第一个小动作开始；被看见后会长成的力量|
|焦虑 / 情绪|情绪承接|2|先看情绪在提醒什么；当下可以怎样接住|
|亲子沟通|关系沟通|3|先把“对错”换成具体场景；双方可能各自在守什么；下一次对话可以这样开始|
|升学 / 专业选择|决策边界|3|报告能帮你看什么；把决定拆成小验证；还要一起考虑什么|
|朋友 / 老师 / 人际|社交场景|2|先定位卡住的场景；给自己一个低压力入口|
|职业方向|职业探索|3|先看什么在消耗你；做一次低成本验证；把优势组合看完整|
|关系去留|关系边界|3|先不急着判断去留；回到一次具体冲突；真正值得继续观察的事|
|心理或医学诊断|专业支持边界|2|这个问题不能由报告判断；建议先整理这些具体情况|
|招聘 / 分班 / 筛选|筛选禁用边界|2|报告不能替代筛选决定；可以安全参考的范围|
|其他自我理解|自我理解|2|你可能卡在这里；先试一个低风险动作|

## 4. 发布阻断条件

出现以下任一情况，报告相关改动不得合并或部署：

1. 所有问题重新显示固定三段标题；
2. 所有问题被强制为相同卡片数量；
3. 四个典型问题返回相同标题组合或高度相似正文；
4. 网页与 PDF 使用不同标题或不同卡片内容；
5. 出现空卡片；
6. 高风险问题进入普通建议模式；
7. `node scripts/test-report-issue-answer-modes.js` 未通过。

## 5. 典型验收组合

同一份报告同时选择：

- 适合哪种学习方式（听·看·动手）；
- 怎么激励他主动学（内驱力）；
- 开始顶嘴 / 叛逆，怎么沟通不炸；
- 考试焦虑 / 输不起怎么疏导。

四题必须呈现四种不同标题组合和明显不同正文，且正式报告固定模块保持不变。
