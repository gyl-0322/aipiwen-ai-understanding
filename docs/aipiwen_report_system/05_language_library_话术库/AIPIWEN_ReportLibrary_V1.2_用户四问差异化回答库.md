# AIPIWEN Report Library V1.2 用户四问差异化回答库

状态：V1.2 内容资产  
用途：正式报告末尾“用户自选 4 个问题”的差异化回答素材  
目标：避免四个问题答案一模一样；按年龄、问题类型、指标线索生成不同回答  
安全等级：自动输出需过滤；高风险问题只降级或转人工

## 1. 总原则

用户选择的四个问题，不能使用同一段兜底模板。

每个问题必须至少根据以下因素差异化：

```text
年龄阶段
问题类型
用户原话
TRC / ATD / 左右脑 / 性格类型 / 学习通道 / 行为模式 / 五大功能区
风险等级
```

内部可以保留“机制 → 做法 → 积极意义 → 继续观察”的完整思考链，但前台不应强制显示成三段式。

更合适的方式是“卡型制”：

```text
先判断问题类型
→ 再选择合适的卡片结构
→ 每张卡只承载一个清楚意图
→ 不为了凑三段而硬写
```

有些问题适合三张卡，有些问题适合一段温和承接加一个清单，有些问题只适合降级和转人工。判断标准不是“结构统一”，而是“用户读起来像一个懂他的人在回答这个问题”。

## 2. 问题分类

| issueType | 典型问题 | 风险 |
|---|---|---|
| learning_method | 学习方法、偏科、文理、阅读、记忆 | R0/R1 |
| homework_dragging | 作业拖拉、不启动、磨蹭 | R1 |
| emotion_regulation | 容易生气、焦虑、哭、输不起 | R1-R3 |
| parent_child_communication | 顶嘴、一说就吵、亲子冲突 | R1/R2 |
| social_relationship | 同伴、交友、人际引导 | R1/R2 |
| education_decision | 选科、升学、专业选择 | R2/R3 |
| career_direction | 职业方向、转型、工作选择 | R1/R2 |
| self_understanding | 自我理解、拖延、压力、边界 | R0/R2 |
| high_risk_diagnosis | ADHD、抑郁、心理疾病、精神问题 | R3 |
| screening_decision | 录用、淘汰、分班、筛选 | R3 |

## 3. 通用生成规则

### 3.1 必须做

- 回答必须贴住用户问的问题标题。
- 每个问题至少引用一个具体报告线索，如学习通道、ATD、行为模式、五大功能区单指、TRC 或性格类型。
- 未成年人问题必须带年龄阶段。
- 成年人问题必须用“你/本人/当前阶段”，不能写“孩子”。
- 每条建议必须能在现实中执行。

### 3.2 禁止做

- 四个问题都写“这个问题不能只看表面行为……”
- 四个问题都写同一套“TRC、ATD、左右脑、五大功能区一起看”。
- 不同问题只替换标题，正文相同。
- 不管什么问题都强制三张卡。
- 为了凑结构，把一句能讲清的话拆成三段废话。
- 把高风险问题包装成普通建议。
- 对升学、职业、关系做确定结论。
- 对心理、医学、疾病做判断。

### 3.3 前台卡型选择规则

#### 卡型 A：行为拆解型

适用：

- 作业拖拉
- 顶嘴
- 情绪爆发
- 手机停不下来
- 不启动
- 不自信

推荐结构：

```text
卡 1：这不是单纯不听话
卡 2：先从哪个小动作开始
卡 3：这个特质如果被看见，会长成什么力量
```

说明：

这类问题适合三张卡，因为用户需要先被安住，再获得方法，再看到希望。

#### 卡型 B：学习诊断型

适用：

- 偏科
- 学习方法
- 文理/选科
- 阅读
- 记忆

推荐结构：

```text
先给一句总判断
再给“观察清单”
最后给“下一步试法”
```

前台可以呈现为两张卡：

1. “先别急着定方向”
2. “接下来观察这 3 个点”

不一定需要第三张“积极意义”，否则容易显得套话。

#### 卡型 C：重大决策降级型

适用：

- 升学决策
- 职业重大转向
- 关系去留
- 是否录用/分班/淘汰

推荐结构：

```text
一段温和边界说明
一张“可以参考的维度”
一张“建议人工一起看”
```

说明：

这类问题不适合写成“为什么会这样 / 怎么应对 / 未来可期”。因为用户问的是重大决定，自动报告不能假装能给答案。

#### 卡型 D：情绪/心理高风险承接型

适用：

- ADHD
- 抑郁
- 焦虑
- 心理疾病
- 精神问题
- 持续睡眠/情绪严重受影响

推荐结构：

```text
一段：这个问题不适合直接用报告判断
清单：建议整理哪些具体情况
提示：如持续影响生活，建议专业支持
```

说明：

这类问题不要做“积极意义”卡。否则会显得轻飘，也可能弱化风险。

#### 卡型 E：关系沟通型

适用：

- 亲子三观差
- 一说就吵
- 和伴侣适不适合
- 同伴冲突

推荐结构：

```text
卡 1：先把关系判断换成具体场景
卡 2：双方可能各自在守什么
卡 3：下一次对话可以怎么开口
```

说明：

关系问题可以三张卡，但标题不能像系统分类，要像人在帮用户把局面拆开。

#### 卡型 F：自我理解型

适用：

- 道理都懂就是拖
- 总想让别人满意
- 不知道适合什么
- 职业方向摇摆

推荐结构：

```text
一句共鸣式开头
一张“你可能卡在这里”
一张“先试一个低风险动作”
一句收束：这不是给你定型
```

说明：

成年人自我理解类问题，语气要像陪他整理自己，而不是像老师讲课。

### 3.4 卡片数量规则

前台卡片数量建议：

| 问题类型 | 建议卡片数量 | 原因 |
|---|---:|---|
| 行为拆解型 | 3 | 需要安住、解释、行动 |
| 学习诊断型 | 2-3 | 重点是观察和试法，不必硬凑希望卡 |
| 重大决策降级型 | 2-3 | 边界优先，不能假装给决定 |
| 情绪/心理高风险型 | 2 | 不做积极意义包装 |
| 关系沟通型 | 3 | 需要从判断转场景，再给对话入口 |
| 自我理解型 | 2-3 | 更像陪伴式整理，少一点模板感 |

硬性要求：

- 任何显示出来的卡都必须有内容。
- 不允许空卡。
- 不允许只显示标题。
- 不允许四个问题全部同一张数、同一标题、同一正文节奏。
- 如果一个问题两张卡就能讲清，不要为了统一强行三张。

## 4. 小学 7-12 岁回答素材

### 4.1 作业拖拉 / 一催作业就崩溃

适用问题：

- 一催作业就崩溃发脾气
- 作业拖拉/磨蹭怎么破
- 怎么激励他主动学

回答素材：

```text
先看背后的机制：
这类表现不一定是孩子不想学。很多小学阶段的拖拉，是“任务启动”卡住了：题目还没开始，心里已经觉得这件事很大、很难、会被催、会被评价。如果报告里体觉精细入口或ATD节奏偏敏感，就更容易出现“还没写，身体先抗拒”的状态。

可以先做的小动作：
不要一上来问“你怎么还不写”。先把任务缩小到第一个动作，比如“先把作业本打开，写日期就好”。再把时间缩短到5-10分钟，让孩子先进入，而不是马上完成。完成后只反馈具体动作：“你刚才已经开始了”，不要急着追加新要求。

值得保留的力量：
拖拉背后有时也藏着谨慎、怕错、想做好。只要入口被拆小，孩子不是没有能力推进，而是需要先从“我能开始”长出“我能完成”。
```

### 4.2 不爱阅读 / 看书坐不住

```text
先看背后的机制：
不爱阅读不一定是阅读能力差，也可能是输入通道没有对上。小学阶段如果视觉图像入口不强，或者听觉/体觉参与更明显，只靠“坐着看字”会很耗能。

可以先做的小动作：
先换入口：可以听一段再看一段，可以让孩子讲给你听，也可以用图表、角色、场景把文字变成立体画面。不要一开始就追页数，先追“有没有进入故事”。

值得保留的力量：
有些孩子不是不爱知识，而是不爱被迫用单一方式吸收。找到入口后，阅读会从任务变成理解世界的方式。
```

### 4.3 在学校和家里表现不一样

```text
先看背后的机制：
孩子在学校和家里不同，不代表他装，也不代表家长看错了。学校有规则、同伴、老师和集体节奏，家里有安全感和情绪出口，两个环境调用的是不同反应。

可以先做的小动作：
分别记录两个场景：学校里什么时候好，家里什么时候爆；不要只问“你为什么在家这样”。可以问：“你在学校忍住了什么？回家最想放下什么？”

值得保留的力量：
这说明孩子有场景切换能力，只是回到安全环境后，没学会更温和地释放。我们要做的不是压住他，而是帮他找到更好的出口。
```

## 5. 初中 13-15 岁回答素材

### 5.1 顶嘴 / 一说就吵

```text
先看背后的机制：
初中阶段的顶嘴，很多时候不是单纯不尊重，而是孩子开始争取“我也有想法”。如果ATD反应快、听觉语气敏感，家长一句提醒很容易被他听成否定；如果精神功能目标感强，他会更想证明自己不是被安排的人。

可以先做的小动作：
先减少连续追问，把一句话改成一个具体请求。比如不说“你怎么又这样”，而说“我们先把手机放下，十分钟后再说作业”。冲突后不要马上复盘道理，等情绪降下来再问：“刚才哪句话让你最不舒服？”

值得保留的力量：
顶嘴背后也可能有表达欲、边界感和自我意识。被正确引导后，它不是问题，而会变成更清楚地表达自己。
```

### 5.2 手机/游戏怎么约定不对抗

```text
先看背后的机制：
手机问题表面是自控，背后常常是压力出口、即时反馈和边界协商。初中阶段如果学习压力大、成就反馈少，手机会变成最容易获得掌控感的地方。

可以先做的小动作：
不要只靠没收。先约定“什么时候用、用多久、用完做什么”，最好写成双方都能看到的规则。把替代活动提前准备好，不要等孩子已经沉进去再临时拉出来。

值得保留的力量：
孩子不是只能被手机吸走，他是在寻找轻松、反馈和掌控。把这些需求看见后，规则才更容易被接受。
```

## 6. 高中 16-18 岁回答素材

### 6.1 文理/选科，天赋更偏哪边

```text
先看背后的机制：
选科不能只看一次成绩，也不能只看“喜欢哪科”。更稳的看法是：他更容易从哪种信息入口进入学习。右食逻辑强，通常更容易抓规则和因果；左食空间/创意强，通常更容易从图像、结构和策略进入；学习通道和ATD也会影响他在课堂和考试里的表现。

可以先做的小动作：
拿两门代表性科目做两周观察：听课时能不能跟上，作业卡在哪里，错题是不会、慢、粗心，还是不会迁移。再分别尝试“公式步骤法、图像结构法、讲题复述法”，看哪一种明显更省力。

值得保留的力量：
选科不是给孩子贴“文科/理科”的标签，而是帮他找到更适合长期投入的学习入口。方向可以参考报告，但最终还要和兴趣、成绩、学校资源和现实压力一起看。
```

### 6.2 升学决策：冲名校还是选适合专业

风险：R2/R3，只能降级为观察维度。

```text
这个问题不适合用报告直接替你做决定。报告可以帮你看学习方式、承压节奏、优势入口和容易卡住的地方，但不能保证升学结果，也不能替代学校、家庭和专业咨询。

更稳的做法是先整理三个维度：第一，当前成绩和可提升空间；第二，孩子更能长期投入的学习方式；第三，这个选择会带来什么压力和支持条件。把这三点放在一起，才比单看天赋更接近真实决策。

如果这个选择已经牵涉重大升学路径，建议人工一起看具体资料，而不是自动生成一个方向结论。
```

### 6.3 考试焦虑 / 输不起怎么疏导

风险：R2/R3。

```text
这个问题需要谨慎看。报告不能判断孩子是否有心理问题，也不能直接给诊断。它能做的是帮你观察：焦虑主要发生在考试前、考试中，还是考后评价时；影响的是睡眠、食欲、学习效率，还是亲子关系。

可以先做的小动作是：把“不要紧张”换成具体支持，比如考前固定复盘清单、考后只复盘一个可改进点、不要在情绪最高时追问分数。如果持续影响生活和学习，建议寻求专业支持。

孩子在意结果，也可能说明他有责任感、标准感和想变好的愿望。我们要保护这份愿望，而不是让它变成自我攻击。
```

## 7. 大学 / 刚毕业 19-25 岁回答素材

### 7.1 专业不喜欢，要不要转方向

```text
先看背后的机制：
这个问题不是简单的“喜不喜欢”，而是当前专业有没有持续调用你的优势入口。如果你的强项在表达、观察、创意或操作，但专业长期只要求另一种输入方式，就会觉得耗能。

可以先做的小动作：
不要马上推翻现状。先做小范围验证：找一个相关方向的小项目、实习、课程或访谈，观察自己是更有能量，还是只是逃离当前压力。

值得保留的力量：
不喜欢现在的专业，不等于之前选错了人生。它可能是在提醒你，需要把能力放到更合适的场景里。
```

### 7.2 找工作不知道适合什么

```text
先看背后的机制：
适合什么工作，不能只靠一个标签判断。更应该看你在什么任务里更容易进入状态：是逻辑分析、表达沟通、创意构思、执行推进，还是观察协调。

可以先做的小动作：
把目标岗位拆成每天真实要做的事，而不是只看岗位名称。再用报告里的功能区去对照：哪些任务会让你省力，哪些会长期消耗。

值得保留的力量：
职业方向不是一次定死的答案，而是一轮轮验证出来的路径。先找到更省力的任务结构，比急着找“天命职业”更可靠。
```

## 8. 成年 26-40 岁回答素材

### 8.1 道理都懂，就是一直拖

```text
先看背后的机制：
成年人拖延常常不是“不懂道理”，而是任务太大、反馈太远、压力太满，身体和情绪先关机。如果体觉精细入口偏弱，或ATD对压力反应明显，就更容易出现“明知道要做，但一直启动不了”。

可以先做的小动作：
把任务切到小到不能再小：不是“写方案”，而是“打开文档写三个标题”；不是“开始运动”，而是“穿上鞋出门五分钟”。同时给自己一个外部反馈点，比如约一个人看进度。

值得保留的力量：
拖延背后有时是标准感和保护机制。你不是没有能力，而是需要把启动门槛降下来，让行动先发生。
```

### 8.2 总想让别人满意，很难拒绝

```text
先看背后的机制：
这类问题往往和听觉敏感、关系线索捕捉、责任感或自我管理有关。你可能很早就听出别人期待，也很快接住别人的情绪，于是还没来得及问自己愿不愿意，就已经先答应了。

可以先做的小动作：
先不练“直接拒绝”，练“延迟答复”。比如先说：“我看一下时间再回复你。”给自己一个缓冲，就能把别人的期待和自己的真实承受力分开。

值得保留的力量：
你在意别人感受，这本身是关系能力。要调整的不是这份敏感，而是给它加上边界。
```

## 9. 高风险问题降级模板

### 9.1 心理/医学/ADHD/抑郁/焦虑

```text
这个问题不适合直接用报告判断。报告不能判断心理疾病、医学问题或临床诊断。

更稳的做法是先整理：具体表现是什么，持续多久，在哪些场景出现，是否影响睡眠、学习、工作或关系。如果已经明显影响生活，建议寻求专业支持。

报告可以帮助你理解行为线索，但不能替代专业评估。
```

### 9.2 关系去留

```text
这个问题不适合自动给出“该不该继续”的结论。

报告可以帮助你拆一个具体冲突场景：你在意什么，对方在意什么，双方表达方式哪里错位。但它不能替你判断分手、继续、谁对谁错。

如果愿意，可以先从最近一次冲突开始看，而不是直接问关系结果。
```

### 9.3 企业招聘 / 学校分层

```text
这份报告不能用于录用、淘汰、分班、筛选或重点培养名单。

如果有充分授权，它最多用于理解沟通支持、学习支持或协作方式，不能作为人事或教育处置依据。
```

## 10. 质量检查清单

四问回答生成后必须检查：

- 四个问题标题不同，正文也必须不同。
- 每个问题至少有一个场景化解释。
- 每个问题至少有一个具体动作。
- 每个问题至少有一个积极意义或可保留力量。
- 高风险问题没有生成普通建议。
- 成年人报告没有孩子称谓。
- 未成年人报告没有职业/升学保证。
- 没有“天生就是”“一定会”“父母导致”“心理问题”等禁用表达。
