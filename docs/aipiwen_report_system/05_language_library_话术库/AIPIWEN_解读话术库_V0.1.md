# AIPIWEN 解读话术库 V0.1

## 基础语气

- 先看见，再解释。
- 先理解眼前困扰，再连接长期特点。
- 用温和、具体、可执行的话替代抽象理论。

## 推荐表达

- 「这个行为可能不是故意对抗，而是在表达一个还说不清的需求。」
- 「这份报告只帮助我们多一个理解角度，不是给任何人贴标签。」
- 「我们先不急着判断对错，先看看这个行为背后发生了什么。」
- 「你可以先试一件小事，看关系有没有一点松动。」

## 禁止表达

- 「他就是这种人格。」
- 「这是天生改不了。」
- 「你有心理问题。」
- 「这个孩子有问题。」
- 「测出来你不适合做这个。」

## 适用场景

- 个人完整报告
- 亲子关系合看报告
- 亲密关系合看报告
- 团队协作理解报告
