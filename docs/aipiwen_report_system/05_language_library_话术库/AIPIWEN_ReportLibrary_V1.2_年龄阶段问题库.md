# AIPIWEN Report Library V1.2 年龄阶段问题库

状态：V1.2 内容资产  
用途：上传报告、行为理解入口、正式报告用户自选问题、人工解读前置问询  
核心原则：问题必须先看年龄阶段，再呈现场景；不能所有年龄段共用同一批问题。

## 1. 总原则

不同年龄的人，面对的是不同的发展任务。  
因此前台问题、报告回答、人工解读承接，都必须先判断年龄段。

禁止：

- 幼儿和高中生看到同一批问题。
- 成年人报告里出现“您孩子怎样怎样”。
- 儿童报告里出现职场中年问题。
- 所有人都套“学习成长 / 沟通相处 / 情绪心理 / 关系引导”同一套选项。

推荐流程：

```text
年龄 / 身份
→ 生命周期阶段
→ 常见困扰
→ 可选问题
→ 风险等级
→ 对应回答库
```

## 2. 年龄段划分

| ageStage | 年龄 | 页面称谓 | 报告对象 | 主要任务 |
|---|---:|---|---|---|
| preschool | 3-6 | 孩子 | 孩子 | 规则感、分离、情绪表达、身体发展 |
| school | 7-12 | 孩子 | 孩子 | 作业、阅读、专注、学习习惯、同伴 |
| junior_teen | 13-15 | 孩子 / 青少年 | 孩子 | 青春期、情绪、同伴、学习动力、自我边界 |
| senior_teen | 16-18 | 孩子 / 青少年 | 孩子 | 选科、考试、升学压力、自我认同 |
| young_adult | 19-25 | 本人 | 本人 | 专业、职业探索、关系、独立生活 |
| adult | 26-40 | 本人 | 本人 | 职业节奏、关系、育儿、压力管理 |
| mature_adult | 40+ | 本人 | 本人 | 转型、家庭责任、生命回顾、协作边界 |

## 3. 幼儿 3-6 岁问题库

### 3.1 推荐页面提示

```text
最近最让你困惑的，是孩子在哪些场景里的反应？
```

### 3.2 常见问题

| 问题 | 风险 | 适合输出方向 | 禁止方向 |
|---|---|---|---|
| 分离时哭闹，很难安抚 | R1 | 安全感、过渡仪式、分离练习 | 依恋障碍、心理问题 |
| 不愿意遵守规则，总说不要 | R1 | 边界感、选择权、规则可视化 | 叛逆、不听话 |
| 情绪来得很快，哭闹停不下来 | R1 | 情绪调节、身体安抚、共情命名 | 情绪异常 |
| 不愿意自己穿衣吃饭 | R0/R1 | 体觉精细、独立练习、第一小步 | 懒、笨 |
| 害怕新环境，不敢尝试 | R1 | 安全预告、低压尝试、陪伴退出 | 胆小没出息 |
| 总是坐不住、想动 | R1/R2 | 体觉需求、活动窗口、短任务 | 多动症、ADHD |

### 3.3 输出语气

幼儿段要更温柔，避免讲复杂指标。  
重点是帮助家长看见：孩子不是故意闹，而是在学习表达、分离、规则和身体控制。

## 11. 年龄段问题库接入规则

前台问题选择必须：

1. 先选择年龄段。
2. 根据年龄段切换常见问题。
3. 允许用户自由输入。
4. 自由输入命中高风险时，以自由输入为准提升风险等级。
5. 报告回答必须使用对应年龄段称谓。
6. 成年人报告禁止出现“孩子/家长”错位称谓。
7. 未成年人报告禁止输出决定性升学、职业或心理判断。

## 12. 测试要求

至少测试：

- 同一个“拖拉”问题，在小学、初中、成人三种年龄段输出不同。
- 同一个“关系”问题，在高中亲子和成人亲密关系场景输出不同。
- 同一个“未来方向”问题，在高中升学、大学就业、40+转型场景输出不同。
- 自由输入高风险词时必须降级。
- 成年人报告不得出现“孩子怎样怎样”。
