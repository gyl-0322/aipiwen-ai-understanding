# AIPIWEN Report Library V1.2 五大功能区独立知识卡

状态：V1.2 内容资产  
用途：供正式报告、Report Knowledge Index、人工解读和测试样本引用  
来源：老师解读录音、现有 `api/generate-report.js` 单指比较规则、`api/guest-chat.js` 十指脑区字典、Report OS 安全边界  
安全等级：前台可用需安全改写；禁止医学、诊断、筛选、命定化表达

## 1. 总原则

五大功能区必须拆成五个独立页面或独立模块：

1. 精神功能（拇指系统）
2. 思维功能（食指系统）
3. 体觉功能（中指系统）
4. 听觉功能（无名指系统）
5. 视觉功能（小指系统）

每个功能区都由两根手指共同构成，但报告解释时不能把两根手指简单相加后与个人单指均值比较。

正确逻辑是：

```text
第一步：每根手指分别与个人均值比较
第二步：判断每根手指高 / 低 / 接近均值的表现
第三步：比较左右两根手指谁更容易先被调动
第四步：结合年龄、场景、学习/行为/沟通问题给建议
```

禁止逻辑：

```text
右手指 + 左手指 = 某功能总分
再拿这个总分和个人单指均值比较
然后得出“某功能高/低”
```

这会导致错误判断。功能区合计可以用于总览图或能力地图，但不能替代单指解释。

## 2. 前台统一表达原则

### 2.1 可以出现的表达

- “这根手指对应的是……”
- “它更像是一个入口，不是结论。”
- “数值高，说明这一路径更容易被调动；也可能因为太顺而带来急、满、停不下来。”
- “数值低，不代表没有能力，而是需要更明确的场景、步骤或练习来带动。”
- “两边差异明显时，通常意味着先从高的一侧进入，再慢慢补低的一侧。”
- “所有判断都要回到真实行为里验证。”

### 2.2 禁止出现的表达

- “这个功能决定……”
- “这个人天生就是……”
- “这说明孩子有问题。”
- “这个数值低就是短板。”
- “这个数值高就一定适合……”
- “可以据此筛选、录用、分层、淘汰。”
- “能预测未来职业 / 升学 / 命运。”

## 3. 精神功能（拇指系统）

### 3.1 对应手指

| 手指 | 对应功能 | 报告解释方向 |
|---|---|---|
| 右拇 R1 | 开创力 / 目标感 / 对外主导 | 发起、带头、目标掌握、号召、外在执行 |
| 左拇 L1 | 管理力 / 自我纪律 / 对内主导 | 自我管理、计划判断、承压、自制、内在执行 |

精神功能看的是一个人如何发起、坚持、管理自己，以及如何面对目标和压力。

右拇更像“向外发动”的力量：想做、敢做、愿意带头、愿意承担目标。  
左拇更像“向内管理”的力量：能不能稳住自己、守住计划、承接压力、把事情推进到底。

### 3.2 单指高低解释

#### 右拇 R1 高

可能表现：

- 有目标感，喜欢看到方向和结果。
- 容易在事情里主动站出来，愿意带动别人。
- 对挑战、成就、突破比较有反应。
- 被赋予责任时，反而更容易进入状态。

可能卡点：

- 太想推进时显得急、硬、没耐心。
- 对没有目标感的任务容易烦。
- 如果别人不配合，容易直接上手或控制节奏。

安全表达：

```text
右拇高的人，通常不是不能配合，而是更需要知道“这件事为什么值得做”。目标一清楚，他的能量就容易被点燃。
```

#### 右拇 R1 低

可能表现：

- 不太主动抢发起权。
- 对大目标、大口号反应不强。
- 更适合在清楚结构里慢慢进入。
- 被催“你要有目标”时，反而容易退开。

优势：

- 不容易盲目冒进。
- 能减少冲动决策。
- 适合先观察，再选择是否投入。

安全表达：

```text
右拇低不是没目标，而是目标不能靠外部口号硬压出来。更适合先给一个能完成的小目标，让他在完成感里慢慢启动。
```

#### 左拇 L1 高

可能表现：

- 自我要求高，愿意管理进度。
- 对规则、责任、计划比较敏感。
- 在需要稳定执行、承压、收尾的事情里更能扛。
- 能把外部要求转成自己的内部要求。

可能卡点：

- 容易给自己压力。
- 可能显得较真、紧绷。
- 如果环境反复变化，容易担心失控。

安全表达：

```text
左拇高的人，内在有一套“我要把事情做好”的管理系统。被看见时，它会变成责任感；被压得太狠时，也可能变成内耗。
```

#### 左拇 L1 低

可能表现：

- 自我管理需要外部结构支持。
- 计划容易停留在想法里。
- 遇到长期任务时，容易需要提醒、陪跑或阶段反馈。
- 压力太大时，可能先逃开或拖延。

优势：

- 不容易过度自责。
- 更灵活，不一定被规则捆住。
- 适合用外部工具补计划，而不是靠意志硬撑。

安全表达：

```text
左拇低不等于没有自律，而是自律更需要被“搭出来”：清楚的步骤、固定的提醒、看得见的进度，比一句“你要自觉”更有效。
```

### 3.3 左右差异解释

#### 右拇明显高于左拇

倾向：

- 发起欲、目标感、对外推动更强。
- 想做大事、想带动别人，但内在计划和稳定收尾需要补结构。

报告表达：

```text
这类人像是先点火再搭轨道。能量起来很快，但如果没有清楚计划，就容易前面冲得很猛，后面靠意志硬撑。
```

建议：

- 先把目标拆成阶段。
- 让“想做”变成“今天做哪一步”。
- 避免只给愿景不给路径。

#### 左拇明显高于右拇

倾向：

- 内在管理、责任感、承压能力更强。
- 不一定主动抢发起权，但一旦接下任务，往往更能稳住。

报告表达：

```text
这类人不一定一开始就站到最前面，但只要任务被他接住，他会更在意有没有做到、有没有收好尾。
```

建议：

- 给明确职责和边界。
- 少用刺激式激将，多用信任式托付。
- 帮他把责任感从压力变成成就感。

#### 两拇指都高

倾向：

- 目标感和管理力都强。
- 有推进力，也有承接力。
- 适合承担复杂任务或带队。

风险：

- 容易把自己绷太紧。
- 对低效率环境没耐心。
- 容易觉得别人跟不上。

#### 两拇指都低

倾向：

- 不适合用高压目标直接启动。
- 需要外部结构、鼓励、小胜利、清晰反馈。

优势：

- 不容易一味冲动。
- 能在被支持后稳稳长出自己的节奏。

前台安全表达：

```text
精神功能双低不代表没能力，而是不能靠“你要有目标”硬推。更有效的是先让他在一个小任务里体验到“我能做到”，目标感才会慢慢长出来。
```

## 4. 思维功能（食指系统）

### 4.1 对应手指

| 手指 | 对应功能 | 报告解释方向 |
|---|---|---|
| 右食 R2 | 逻辑推理 / 数学 / 规则理解 | 语言逻辑、因果、分析、解题框架 |
| 左食 L2 | 创意 / 空间想象 / 策略 | 画面、空间、构思、策略、创意发散 |

思维功能看的是一个人怎么想、怎么组织信息、怎么把想法说出来或转成方案。

右食更像“讲得清、推得动”的逻辑线。  
左食更像“想得开、搭得出”的空间和创意线。

### 4.2 单指高低解释

#### 右食 R2 高

可能表现：

- 喜欢找规律、讲道理、问为什么。
- 数学、规则、逻辑题更容易进入。
- 表达时想把因果讲清楚。
- 适合用步骤、公式、框架学习。

风险：

- 容易较真。
- 可能嫌别人讲得不清楚。
- 压力大时会卡在“没想明白”。

#### 右食 R2 低

可能表现：

- 不太喜欢纯抽象推理。
- 听道理未必马上进脑。
- 更需要例子、图像、实操来辅助理解。

优势：

- 不一定被规则捆住。
- 可能更愿意从经验、感受、画面进入。

#### 左食 L2 高

可能表现：

- 画面感、空间感、创意和策略感更强。
- 容易想到别人没想到的路径。
- 做设计、搭建、构思、布局时更有感觉。
- 老师录音中提到，这类高值常会“想得比别人多、想得更全面”。

风险：

- 想法多，表达不一定跟得上。
- 容易跳跃，别人听起来像跑题。
- 如果右食跟不上左食，可能“脑子里有很多，但说不完整”。

#### 左食 L2 低

可能表现：

- 不喜欢凭空构思。
- 更适合有清楚步骤和具体样例。
- 空间、创意类任务需要更多外部材料刺激。

优势：

- 总结能力可能更稳定。
- 不容易过度发散。
- 适合标准化、流程化、复盘型任务。

### 4.3 左右差异解释

#### 右食明显高于左食

倾向：

- 语言逻辑输出快于空间构思。
- 容易先答应、先表达，但脑内画面未必完全跟上。

报告表达：

```text
他不是故意说话不算数，有时更像是嘴先答应了，脑子里的画面还没真正接住。让他复述一遍要求，会比反复责备更有效。
```

建议：

- 重要要求让他复述。
- 把口头约定写下来。
- 让他说清“第一步做什么”。

#### 左食明显高于右食

倾向：

- 想法、画面、策略多于语言表达。
- 自己以为讲清楚了，别人可能只听到一部分。

报告表达：

```text
他的脑子里可能已经走了十步，但说出来只有三步。不要急着说他表达差，可以请他画出来、写关键词，或者一步一步讲给你听。
```

建议：

- 用图、草稿、流程图辅助表达。
- 不急着打断，先让他把画面倒出来。
- 训练“想法到语言”的转换。

## 5. 体觉功能（中指系统）

### 5.1 对应手指

| 手指 | 对应功能 | 报告解释方向 |
|---|---|---|
| 右中 R3 | 小肌肉精细 / 操作细节 / 写字手工 | 写字、手工、细节操作、任务启动与操作速度 |
| 左中 L3 | 大运动 / 身体节奏 / 耐力坚持 | 运动、律动、坚持、身体协调、耐力 |

体觉功能看的是一个人如何通过身体进入任务，以及执行、操作、坚持的节奏。

### 5.2 单指高低解释

#### 右中 R3 高

可能表现：

- 动手快，细节操作进入快。
- 写字、手工、整理小任务更容易上手。
- 适合通过“做一遍”来理解。

风险：

- 可能嫌慢。
- 对重复细节要求高时容易急。

#### 右中 R3 低

可能表现：

- 写字、整理、收拾、手工、细节操作启动慢。
- 容易被看成拖拉。
- 不一定不想做，而是身体入口慢。

安全表达：

```text
右中低时，拖拉常常不是态度问题，而是细节操作启动慢。把任务拆成第一个动作，比反复催促更有效。
```

#### 左中 L3 高

可能表现：

- 体能、律动、耐力、运动协调更容易被调动。
- 适合用身体活动释放压力。
- 做长期训练时，身体承接力较好。

#### 左中 L3 低

可能表现：

- 对长时间坚持、运动耐力、身体协调要求高的任务容易累。
- 不适合一上来就拉长训练时间。
- 需要短时、多次、可见反馈。

### 5.3 左右差异解释

#### 右中高、左中低

倾向：

- 细节操作可以，但持续耐力不足。
- 能开始做小事，但长时间坚持容易掉线。

#### 左中高、右中低

倾向：

- 大运动和身体能量较强，但细节操作慢。
- 运动场景可能很有活力，写作业、写字、整理却容易拖。

报告表达：

```text
这不是“能动却不肯写”，而是大身体和小手部调用的入口不同。可以先让身体动起来，再回到精细任务。
```

## 6. 听觉功能（无名指系统）

### 6.1 对应手指

| 手指 | 对应功能 | 报告解释方向 |
|---|---|---|
| 右无名 R4 | 语言表达 / 口语记忆 / 听后复述 | 语言、表达、记忆、沟通措辞 |
| 左无名 L4 | 音感 / 语气 / 言外之意 / 情绪声调 | 音乐、节奏、语气、共情、言外之意 |

听觉功能看的是一个人如何通过声音、语言、语气和听觉线索理解世界。

### 6.2 单指高低解释

#### 右无名 R4 高

可能表现：

- 听讲、朗读、复述、讲题更有效。
- 语言表达和口头记忆更容易被调动。
- 适合通过“讲出来”巩固学习。

#### 右无名 R4 低

可能表现：

- 单靠口头讲解容易漏。
- 听了五件可能只记住两件。
- 需要文字、图像或动作辅助。

安全表达：

```text
这不是故意没听，而是口头信息不容易一次进脑。重要事情可以写下来，或让他复述一遍。
```

#### 左无名 L4 高

可能表现：

- 对语气、节奏、音乐、情绪声调敏感。
- 容易听出别人没明说的意思。
- 共情、同理、听出氛围变化能力较强。

风险：

- 容易被语气伤到。
- 也可能因为听到太多“话外音”而内耗。

#### 左无名 L4 低

可能表现：

- 对语气、节奏、言外之意不那么敏感。
- 沟通更直接，少受情绪声调干扰。

优势：

- 在面试、筛选、执行场景中更可能抓重点，不被过多情绪信息带走。
- 不容易被声音氛围牵着走。

### 6.3 左右差异解释

#### 右无名高、左无名低

倾向：

- 能听懂信息和语言，但不一定捕捉情绪细节。
- 沟通直接高效，但可能显得不够柔软。

#### 左无名高、右无名低

倾向：

- 对语气、情绪、氛围敏感，但表达未必同步清楚。
- 容易听出别人状态，却不一定知道怎么说出来。

## 7. 视觉功能（小指系统）

### 7.1 对应手指

| 手指 | 对应功能 | 报告解释方向 |
|---|---|---|
| 右小 R5 | 识人 / 察色 / 方向感 / 外部辨识 | 观察外部线索、识人、方向、环境辨识 |
| 左小 L5 | 色彩审美 / 图像思考 / 内在画面 | 审美、图像、画面感、色彩、设计 |

视觉功能看的是一个人如何通过图像、空间、环境线索和视觉审美理解世界。

### 7.2 单指高低解释

#### 右小 R5 高

可能表现：

- 察言观色、识人辨人、方向感、环境线索捕捉更容易。
- 对细节变化敏感。
- 适合用观察、比较、分类来理解信息。

#### 右小 R5 低

可能表现：

- 容易脸盲、记不住人、迷路、看不出别人脸色变化。
- 不一定是不在乎，而是外部视觉辨识入口弱。

安全表达：

```text
右小低时，不要简单说“没眼力见”。他可能真的没有第一时间捕捉到外部线索，需要更直接的语言提醒。
```

#### 左小 L5 高

可能表现：

- 色彩、审美、图像记忆、画面联想较强。
- 喜欢好看的东西，对搭配、画面、设计有感觉。
- 学习时适合图表、颜色、视觉化材料。

#### 左小 L5 低

可能表现：

- 对图像审美、色彩、画面联想不一定敏感。
- 更适合语言、步骤、逻辑或动作辅助。

优势：

- 不容易被外观过度牵动。
- 做判断时可能更看实际功能和规则。

### 7.3 左右差异解释

#### 右小高、左小低

倾向：

- 更会观察外部现实线索，但不一定偏审美表达。
- 适合识人、辨环境、看细节。

#### 左小高、右小低

倾向：

- 内在画面、审美和图像感强，但外部识人、方向感不一定同步强。
- 可能很会做图、选颜色，却不一定记人或认路。

## 8. 五大功能区输出模板

每个功能区报告页至少包含：

```text
①是什么
说明这个功能区对应哪两根手指，每根手指代表什么。

②对当前用户意味着什么
分别写每根手指与个人均值的比较。
再写左右两根手指谁更容易被调动。
说明高/低各自的优势、卡点和现实表现。

③怎么应用
给学习、行为、沟通、接纳方式的具体建议。
必须具体到可观察、可执行。
```

## 9. 质量检查清单

生成报告前必须检查：

- 是否五个功能区分开输出。
- 是否每个功能区都写了两根手指。
- 是否每根手指都单独与个人均值比较。
- 是否没有把两根手指相加去比个人均值。
- 是否写了高值表现、低值表现、优势和卡点。
- 是否写了左右差异。
- 是否写了应用建议。
- 是否避免诊断、标签、筛选、保证、命定化表达。
