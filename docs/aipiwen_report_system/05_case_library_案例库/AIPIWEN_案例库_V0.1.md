# AIPIWEN 案例库 V0.1

## 1. 案例卡格式

每个案例按以下字段登记：

- 案例名称
- 来源
- 适用入口
- 用户看到的行为
- 常见误判
- 可能涉及指标
- 解读逻辑
- AIPIWEN 可用表达
- 建议动作
- 风险边界
- 可用等级：A / B / C / D

等级定义：

| 等级 | 含义 |
| --- | --- |
| A | 前台可直接输出 |
| B | 安全改写后可输出 |
| C | 只供人工专家参考 |
| D | 禁止输出 |

### 2.1 高 TRC 孩子写作业听音乐 / 吃水果 / 玩小物件

- 来源：老师录音价值点，待原文校验。
- 适用入口：行为理解、亲子关系合看。
- 用户看到的行为：孩子写作业时听音乐、吃水果、摸小物件。
- 常见误判：不专心、故意拖拉、不认真。
- 可能涉及指标：TRC、学习通道、体觉功能。
- 解读逻辑：部分孩子需要适度感官输入维持任务节奏。
- AIPIWEN 可用表达：这不一定代表孩子不认真，可能是在用自己的方式维持注意力。
- 建议动作：先观察效率变化，再约定不影响任务的辅助动作。
- 风险边界：不能把所有分心行为都解释为高 TRC。
- 可用等级：B

### 2.2 高 TRC 兴趣班先体验

- 来源：老师录音价值点，待原文校验。
- 适用入口：学习 / 兴趣方向建议、亲子关系合看。
- 用户看到的行为：孩子兴趣变化快，不想长期坚持。
- 常见误判：三分钟热度、不能坚持。
- 可能涉及指标：TRC、开放型、行为模式。
- 解读逻辑：先体验可降低错误长期投入，帮助孩子筛选真实兴趣。
- AIPIWEN 可用表达：可以先用短周期体验确认匹配度，再决定是否长期投入。
- 建议动作：设置 2 到 4 周体验期和复盘问题。
- 风险边界：不能用来逃避必要练习。
- 可用等级：A

### 2.3 体觉型孩子适合户外、运动、玩水、拼搭

- 来源：老师录音价值点，待原文校验。

- 用户看到的行为：孩子喜欢动、摸、拆、搭、跑。
- 常见误判：坐不住、不爱学习。
- 可能涉及指标：体觉通道、体觉功能。
- 解读逻辑：体觉型孩子通过身体和真实体验进入学习。
- AIPIWEN 可用表达：对这类孩子，动手和身体参与往往是进入学习的入口。
- 建议动作：把学习任务改成实验、拼搭、户外观察或动作游戏。
- 风险边界：不替代规则训练和安全边界。

### 2.4 敏感孩子“肚子疼”需要先安慰

- 来源：老师录音价值点，待原文校验。
- 适用入口：行为理解、亲子关系合看。
- 用户看到的行为：孩子紧张或压力下说肚子疼。
- 常见误判：装病、逃避、矫情。
- 可能涉及指标：ATD / 敏感值、体觉功能。
- 解读逻辑：身体不适可能和压力感受有关，需要先接住情绪和身体感受。
- AIPIWEN 可用表达：可以先安抚和确认感受，再观察是否需要就医或调整压力源。
- 建议动作：先陪伴、喝水、休息、询问具体感受，再判断下一步。
- 风险边界：持续疼痛或明显异常必须就医，不能用报告解释替代医疗判断。
- 可用等级：B

### 3.1 高 TRC 写作业低干扰小动作

- card_id: CASE_V02_PARENT_TRC_HOMEWORK_001
- card_type: case
- title: 高 TRC 孩子写作业时允许低干扰小动作
- source: 老师录音转写稿，约 lines 6838-7060、11388-11408、12704-12745
- applicable_entries: behavior_understanding, relationship_report
- usable_level: B
- user_visible_behavior: 孩子写作业时听音乐、吃水果、拿玩具或同时做轻微动作。
- common_misjudgment: 不专心、故意拖拉、不认真。
- related_metrics: TRC, 体觉功能, 听觉功能
- core_logic: 部分高 TRC 或多元化节奏的孩子需要低干扰感官输入维持任务状态，强行要求完全静止反而可能降低效率。

- suggested_action: 约定完成时间和不打扰他人的边界，只观察效率，不频繁打断。
- risk_boundary: 若小动作明显影响作业质量、睡眠或课堂规则，需要结合学校反馈调整。
- confidence_notes: 已在真实录音多个片段出现，但前台仍需结合孩子年龄和任务结果判断。
