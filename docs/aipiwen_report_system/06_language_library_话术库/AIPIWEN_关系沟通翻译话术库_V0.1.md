# AIPIWEN 关系沟通翻译话术库 V0.1

## 1. 使用边界

本话术库用于把关系中的指责句翻译成需求句，不用于判断谁对谁错，不劝分、不劝合、不做医学或心理诊断。

历史资料中的“合盘”只保留在原始文件名或内部资料登记中，AIPIWEN 前台统一使用“合看报告”“关系理解报告”“团队协作理解报告”。

## 2. 亲密关系沟通翻译句

| 原始冲突表达 | AIPIWEN 翻译 | 建议回应 |
| --- | --- | --- |
| 你怎么一点都不在乎我？ | 我需要你更及时地回应我，让我确认这段关系是安全的。 | 我可能反应慢，但我愿意先给你一个回应，再慢慢整理我的想法。 |
| 你太情绪化了。 | 我有点不知道怎么接住你的情绪，也需要一个更清楚的沟通节奏。 | 我现在情绪比较满，我们先暂停 10 分钟，再把事情说清楚。 |
| 你怎么总是不陪我？ | 对我来说，在场和陪伴本身就是关系里的安全感。 | 我可以固定留出陪伴时间，也需要提前说明我的独处时间。 |
| 你说话太啰嗦了。 | 我需要先听到结论，再听原因和细节。 | 我先说结论，再补两个原因，最后说下一步。 |
| 你怎么总是否定我？ | 我需要你先看到我的努力，再提出不同意见。 | 我先说我认可的部分，再说我担心的风险点。 |

## 3. 亲子关系沟通翻译句

| 原始冲突表达 | AIPIWEN 翻译 | 建议回应 |
| --- | --- | --- |
| 你怎么又不认真写作业？ | 我担心你没有进入学习状态，也想知道什么方式更适合你。 | 我们先约定完成时间，你可以保留不影响作业的小动作。 |
| 你怎么这么不听话？ | 我需要确认你是否听懂规则，也需要你承担选择后的责任。 | 我给你两个选择，你选一个，然后复述一下你要负责什么。 |
| 你别总顶嘴。 | 我听到你有自己的想法，但我们需要用更清楚的方式表达。 | 你先说你的理由，我再说我的边界。 |
| 你怎么这么敏感？ | 我看到你现在感受很强，需要先被接住。 | 我先陪你把感受说出来，再一起看下一步怎么做。 |
| 我都是为你好。 | 我希望你未来更稳，但我也需要知道你自己的感受和选择。 | 我先问你怎么想，再一起定一个可执行的小目标。 |

## 4. 合伙人关系沟通翻译句

| 原始冲突表达 | AIPIWEN 翻译 | 建议回应 |
| --- | --- | --- |
| 你怎么总是拖？ | 我需要更明确的时间点和交付节奏。 | 我们把任务拆成节点，今天先确认第一个交付。 |
| 你怎么总是冒进？ | 我需要在行动前看见风险和兜底方案。 | 我先给机会判断，再补风险清单和止损线。 |
| 你是不是不信任我？ | 我需要清楚权责边界，不是要否定你。 | 我们把谁决策、谁复核、谁执行写下来。 |
| 你怎么老改主意？ | 我需要一个反悔和调整规则，否则团队会失去节奏。 | 我们约定决策截止时间，超过时间只在重大风险下调整。 |
| 你只顾自己利益。 | 我需要看见共同目标和收益分配方式。 | 我们把短期收益、长期投入和责任比例重新对齐。 |

## 5. 团队协作沟通翻译句

| 原始冲突表达 | AIPIWEN 翻译 | 建议回应 |
| --- | --- | --- |
| 这个人拖后腿。 | 可能是角色、任务和反馈机制没有对齐。 | 我们先看他适合的任务和当前卡住的环节。 |
| 大家都没执行力。 | 团队可能缺少明确责任人、截止时间和复盘机制。 | 每项任务只定一个负责人、一个截止时间、一个验收标准。 |
| 会议太低效。 | 会前信息、会上决策和会后跟进没有分开。 | 会前发资料，会上只决策，会后发责任清单。 |
| 你们怎么都听不懂？ | 信息表达方式可能不适配团队通道。 | 同一信息同时给口头说明、书面清单和示例。 |
| 创意很多但落不下去。 | 创意者、决策者和执行者角色没有拆开。 | 先收集想法，再指定决策人和执行人。 |

## 6. 禁用表达

- 你们不合适。
- 你们一定会分开。
- 这个孩子就是被家长毁了。
- 这个合伙人不能合作。
- 婚姻一定有问题。
- 注定冲突。
- 天生相克。
- 合盘注定。
