# AIPIWEN 行业合规与安全边界 V0.1

## 1. 总原则

行业大会资料中多次出现标准化、自律规范、伦理红线、隐私保护、未成年人信息保护、脱敏和合规表达要求。AIPIWEN 必须把这些内容转化为产品底线。

## 2. 合规边界清单

| 序号 | 边界 | AIPIWEN 执行规则 |
| --- | --- | --- |
| 1 | 皮纹 / 指纹数据只能作为潜能辅助参考 | 所有报告必须写“理解参考”，不写“结论” |
| 2 | 不能替代临床诊断 | 不输出 ADHD、抑郁、疾病、障碍判断 |
| 3 | 不能绝对化判断 | 禁用“一定、绝对、注定、必然” |
| 4 | 不能预测命运 | 禁用天命、前世、命中注定、生命密码等前台表达 |
| 5 | 不能直接使用玄学化表达 | 统一改写为行为模式、沟通节奏、关系经营方式 |
| 6 | 不能直接输出疾病判断 | 医养、康养、疾病只进入远期研究或内部观察 |
| 7 | 不能夸大科学性 | 不说“已被完全证明”“唯一科学依据” |
| 8 | 需要数据隐私与脱敏 | 报告、截图、案例、训练材料必须去标识化 |
| 9 | 需要用户授权 | 上传报告、多人合看、未成年人资料必须有授权前提 |
| 10 | 未成年人尤其谨慎 | 不贴标签、不预测未来、不对学校/家庭做定性评价 |
| 11 | AI 不能替代专家 | AI 只做辅助解释和初稿生成 |
| 12 | 团队应用不能筛查淘汰 | 只做协作理解和分工建议 |

## 3. 高风险行业表达改写

| 高风险表达 | 风险 | 安全改写 |
| --- | --- | --- |
| 指纹是生命密码 | 玄学化 / 绝对化 | 指纹数据可作为个体差异理解的参考线索 |
| 脑科学证明孩子一定怎样 | 夸大科学性 | 相关研究可作为内部观察方向，不能做个体确定结论 |
| 预防疾病 / 精准医疗 | 医疗承诺 | 医养和健康相关内容仅作远期研究方向 |
| 全生命周期养护 | 康养承诺 | 全生命周期理解与陪伴地图 |
| AI 永生智能体 | 宏大叙事 / 风险表达 | 长期问答与个人知识档案，不做永生承诺 |
| 预测未来人才 | 绝对化 | 提供学习方式、职业探索和发展支持建议 |
| 学校可识别问题孩子 | 标签化 | 帮助家校理解孩子行为背后的需要 |
| 企业人才测评决定岗位 | 过度应用 | 为团队协作和岗位沟通提供参考 |

## 4. 未成年人资料规则

- 只收集完成报告所需的最小资料。
- 未成年人报告必须获得监护人授权。
- 校园场景不得输出“问题孩子”“风险学生”“心理疾病”等标签。
- 班级画像只输出群体学习和沟通建议，不输出个体排名。
- 案例进入报告库前必须脱敏。

## 5. AI 输出前检查

1. 是否把潜能参考写成确定结论。
2. 是否出现医学、心理、脑科学诊断表达。
3. 是否出现命运、玄学、永生、生命能量等前台词。
4. 是否缺少用户授权或资料来源说明。
5. 是否涉及未成年人标签化。
6. 是否夸大行业、官方、科研背书。
7. 是否应升级人工专家。
