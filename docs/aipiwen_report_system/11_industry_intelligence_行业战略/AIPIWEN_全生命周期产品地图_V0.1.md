# AIPIWEN 全生命周期产品地图 V0.1

## 1. 使用边界

行业大会资料中的全生命周期、脑科学、医养、康养内容只可转化为 AIPIWEN 的“理解与陪伴地图”。涉及疾病、医学、康养、脑科学确定性结论的内容，只能作为远期研究方向或内部观察方向，不能作为当前产品承诺。

## 2. 安全版产品地图

| 阶段 / 场景 | 产品方向 | 可输出 | 禁止输出 |
| --- | --- | --- | --- |
| 0-6 岁 | 早期观察与亲子陪伴 | 感官需要、亲子回应、习惯支持 | 预测天赋定型 |
| 7-12 岁 | 学习方式与兴趣启蒙 | 学习通道、兴趣体验、作业方式 | 一次决定长期方向 |
| 13-18 岁 | 学习压力、情绪沟通、自我认同 | 压力沟通、亲子边界、选科探索 | 心理诊断、升学保证 |
| 19-25 岁 | 专业选择、职业探索 | 专业适配线索、职业体验建议 | 职业命定 |
| 26 岁以上 | 自我理解、关系、职业转型 | 自我使用说明、关系合看、职业过渡 | 人生结论 |
| 家庭 | 亲子 / 亲密关系理解 | 沟通翻译、陪伴建议、行动计划 | 劝分劝合、判断家庭 |
| 学校 | 家校成长沟通 | 班级学习方式、家校沟通建议 | 个体排名、风险学生 |
| 企业 | 团队协作与人才适配 | 角色分布、会议机制、协作建议 | 招聘淘汰 |
| 中老年 | 生命回顾与代际理解 | 经验整理、代际沟通、关系理解 | 康养疗效、疾病预防承诺 |

## 3. 产品层级

### 基础层：报告理解

- 快速读懂报告。
- 指标解释。
- 年龄段解释。
- 场景问题解释。

### 应用层：场景报告

- 孩子行为理解。
- 学习方式和兴趣启蒙。
- 亲子关系合看。
- 亲密关系合看。
- 职业探索报告。
- 团队协作理解报告。

### 陪伴层：长期问答

- 围绕同一份报告持续追问。
- 根据用户阶段更新输出重点。
- 记录行动计划和复盘。

### 专家层：复杂问题升级

- 复杂亲子冲突。
- 职业转型。
- 亲密关系深度冲突。
- 团队组织问题。
- 涉及情绪、睡眠、疾病、暴力、自伤风险的问题。

## 4. 远期研究方向

以下方向不进入当前产品承诺：

- 脑科学精确映射。
- 医养、康养、疾病预防。
- 生命能量、永生智能体。
- 基因、健康、医疗结论。
- 中老年认知或疾病相关判断。
