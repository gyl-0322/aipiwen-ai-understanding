# AIPIWEN V3.0 工作台按钮与导航治理矩阵

## 1. 治理原则

1. 六个核心栏目只通过左侧主导航进行全局切换。
2. 页面右上角、右下角和卡片底部不重复放置左侧导航已有的栏目入口。
3. 页面只保留当前页面需要执行的真实动作。
4. 没有事件处理或真实后端能力的按钮必须删除；明确标注“即将开放”且处于 disabled 状态的按钮可以保留。
5. 学习示例客户行可以进入对应的解读示例，这是内容上下文动作，不属于重复导航。
6. 错误页的“重新加载”和“返回登录”属于恢复动作，必须保留。
7. 前台不展示权限隔离、数据归属、绑定模型、管道、入库规则等后台设计语言。

| 控件 | 行为 | 结论 |

## 4. 我的客户

| 控件 | 行为 | 结论 |
| --- | --- | --- |
| 客户扫码上传 | 创建一次性凭证，在当前页展示二维码和服务码 | 保留；依赖 Migration 026 |
| 代客户上传报告 | 创建一次性凭证后进入 `/report-upload.html?token=...` | 保留；依赖 Migration 026 |
| 关闭 | 关闭二维码面板 | 保留 |
| 复制服务码 | 复制当前一次性服务码 | 保留 |
| 学习示例客户行 | 进入 AI 解读示例 | 保留，属于内容动作 |
| 右上“进入解读助手” | 重复左侧导航 | 删除 |
| 右下“进入 AI解读助手” | 重复左侧导航 | 删除 |
| 查看复核记录 | 重复左侧“总部复核 / 规范” | 删除 |

Preview 浏览器运行时已确认原“进入解读助手”链接实际可以进入 `ai-interpreter-session.html`；本次删除是产品去重，不是导航故障修复。

| 控件 | 行为 | 结论 |

| 生成 AI 解读方案 | disabled，明确标注即将开放 | 保留 |

## 6. 解读训练

| 控件 | 原行为 | 结论 |
| --- | --- | --- |

| 查看案例来源 | 重复左侧优秀案例沉淀 | 删除 |

## 7. 总部复核 / 规范

| 控件 | 行为 | 结论 |
| --- | --- | --- |
| 等待中 / 已反馈 / 草稿 | 当前页切换学习示例状态 | 保留 |
| 提交复核 | 只是返回 AI 解读助手，没有真实提交 | 删除 |
| 标记优秀案例 | 只是跳转优秀案例栏目，没有真实标记 | 删除 |

## 8. 优秀案例沉淀

| 控件 | 原行为 | 结论 |
| --- | --- | --- |
| 标记为优秀案例 | 无事件处理和真实写入 | 删除 |
| 查看入库规则 | 无事件处理，并暴露后台设计语言 | 删除 |

页面保留去标识化后的学习示例与案例整理说明，不承诺真实案例写入。

## 9. 通用错误恢复

所有受保护页面继续保留：

- 重新加载：重新打开当前页面；
- 返回登录：进入 `/login.html`。

这些不是栏目导航重复，而是登录或 Session 异常时的必要恢复路径。

## 10. 防回归门禁

自动化测试必须验证：

- 六页左侧导航完整；
- 页面不存在 `class="btn"` 形式的跨栏目重复快捷链接；
- 不存在无处理逻辑的已删除按钮文案；
- 客户页不出现权限、归属或内部步骤设计说明；
- 客户扫码与代上传按钮仍连接真实 BFF；
- AI 解读步骤和复核状态切换仍可用。
