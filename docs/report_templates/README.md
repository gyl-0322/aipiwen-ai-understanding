# AIPIWEN 报告模板登记

本目录只登记未来可用于关系报告与完整报告升级的模板来源。本阶段不接入生成逻辑，不复制模板正文，不自动抽取内容。

## 已登记模板

### 1. 亲密关系合看报告模板

- 参考文件：`天赋测评_夫妻关系合盘解读(1).pptx`
- 未来用途：用于提取「亲密关系合看报告」结构。
- 结构要点：TRC、ATD、性格类型相处、学习通道、行为模式、精神功能、思维功能、体觉、听觉、视觉、总结与相处建议。

### 2. 亲子关系合看报告模板

- 参考文件：`天赋测评_亲子关系合盘解读(1).pptx`
- 未来用途：用于提取「亲子关系合看报告」结构。
- 结构要点：TRC、ATD、性格类型相处、学习通道、行为模式、精神功能、思维功能、体觉、听觉、视觉、总结与教育建议。

### 3. 企业团队协作理解报告模板

- 参考文件：`企业团队合盘报告 (1)(1).pptx`
- 未来用途：用于提取「团队协作理解报告」「企业核心团队协作报告」「合伙人关系合看报告」结构。
- 结构要点：
  1. 开篇定位
  2. 核心理念
  3. TRC 学习潜能板块
  4. ATD 反应速度板块
  5. 性格类型板块
  6. 学习通道板块
  7. 行为模式板块
  8. 五大功能区板块
  9. 综合管理指导

### 4. 合伙人 / 夫妻深度版参考

- 参考文件：`读懂彼此，我们本是最佳合伙人(1).pdf`
- 未来用途：用于提取「合伙人关系合看报告」「亲密关系深度关系说明书」结构。
- 结构要点：看见是开始、关系说明书定位、解码先天差异、从差异到冲突、从冲突到协同、行动计划、从权力斗争到优势整合、亲密关系中的沟通修复与协同成长。

## 当前阶段边界

- 只做模板登记。
- 不接入 AIPIWEN 前端。
- 不接入 API。
- 不改变正式报告生成逻辑。
- 后续在「关系报告模板吸收升级」任务中再做结构提取。
